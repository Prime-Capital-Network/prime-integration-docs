Obtén una lista paginada de representantes en la empresa.

<Note>
  Este endpoint requiere el scope **`BusinessRepresentatives.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Query parameters

<ParamField query="filter_by" type="string">
  Valores aceptados:

  - `Active`
</ParamField>

<ParamField query="name" type="StringSearchFilter">
  Filtrar por el nombre del representante.
</ParamField>

<ParamField query="isSalesPerson" type="BooleanSearchFilter">
  Filtrar por si el representante es un vendedor.
</ParamField>

<ParamField query="isExecutiveAccount" type="BooleanSearchFilter">
  Filtrar por si el representante es un ejecutivo de cuentas.
</ParamField>

<ParamField query="isCustomerService" type="BooleanSearchFilter">
  Filtrar por si el representante pertenece al área de servicio al cliente.
</ParamField>

<ParamField query="isDebtCollector" type="BooleanSearchFilter">
  Filtrar por si el representante es un gestor de cobros o cobrador.
</ParamField>

<ParamField query="isActive" type="BooleanSearchFilter">
  Filtrar por si está activo o no.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/business-representatives?isActive=true&isSalesPerson=true" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch(
  "https://api.primenetcloud.com/v1/business-representatives?isActive=true&isSalesPerson=true",
  {
    method: "GET",
    headers: {
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID",
    },
  }
);

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/business-representatives",
    params={
        "isActive": "true",
        "isSalesPerson": "true",
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

<ResponseField name="isCustomerService" type="boolean">
