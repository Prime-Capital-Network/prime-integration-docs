---
title: "Crear Detalle"
api: "POST /purchase-receptions/{id}/details"
---

Crea un nuevo detalle para una recepción de compra específica.

<Note>
  Este endpoint requiere el scope **`PurchaseReceptions.Write`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la recepción de compra a la que se agregará el detalle.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request POST \
  --url "https://api.primenetcloud.com/v1/purchase-receptions/512/details" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID" \
  --header "Content-Type: application/json" \
  --data '{
    "productId": 88,
    "quantity": 800,
    "purchaseOrderDetailId": 34,
    "productPackagingId": 10,
    "packagingQuantity": 20
  }'
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/purchase-receptions/512/details", {
  method: "POST",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    productId: 88,
    quantity: 800,
    purchaseOrderDetailId: 34,
    productPackagingId: 10,
    packagingQuantity: 20
  }),
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.post(
    "https://api.primenetcloud.com/v1/purchase-receptions/512/details",
    json={
        "productId": 88,
        "quantity": 800,
        "purchaseOrderDetailId": 34,
        "productPackagingId": 10,
        "packagingQuantity": 20
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Example response

```json
{

```

### Response fields

<ResponseField name="id" type="integer">
  Identificador único del detalle de recepción de compra creado.
</ResponseField>

### Errores

<ResponseField name="400 Bad Request">
  La recepción de compra ya ha sido cancelada y no admite nuevos detalles.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PurchaseReceptions.Write` requerido.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ninguna recepción de compra con el `id` especificado en la URL.
</ResponseField>
