Actualiza los datos de una recepción de compra en la empresa.

<Note>
  Este endpoint requiere el scope **`PurchaseReceptions.Write`**.
</Note>

<Warning>
  Este es un reemplazo completo del recurso (PUT). Todos los campos enviados en el body sobrescribirán el estado actual de la recepción. Para cambios parciales, verificar la sección [Actualizar Parcial](/api-reference/purchase-receptions/actualizar-parcial-recepciones).
</Warning>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la recepción de compra a actualizar.
</ParamField>

### Body parameters

<ParamField body="purchaseOrderId" type="integer">
  Identificador de la orden de compra contra la cual se recibe la mercancía.
</ParamField>

<ParamField body="date" type="date" required>
  Fecha de la recepción de compra en formato `YYYY-MM-DD`.
</ParamField>

<ParamField body="vendorId" type="integer">
  Identificador del proveedor (Vendor).

  - Debe ser un asociado con el campo `IsVendor` como true.
</ParamField>

<ParamField body="observations" type="string">
  Observaciones de la recepción de compra. Máximo 250 caracteres.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request PUT \
  --url "https://api.primenetcloud.com/v1/purchase-receptions/512" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID" \
  --header "Content-Type: application/json" \
  --data '{
    "purchaseOrderId": 776,
    "date": "2026-07-15",
    "vendorId": 142,
    "observations": "Recepción completa del contenedor MSCU1234567"
  }'
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/purchase-receptions/512", {

  body: JSON.stringify({
    purchaseOrderId: 776,
    date: "2026-07-15",
    vendorId: 142,
    observations: "Recepción completa del contenedor MSCU1234567"

});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.put(
    "https://api.primenetcloud.com/v1/purchase-receptions/512",
    json={
        "purchaseOrderId": 776,
        "date": "2026-07-15",
        "vendorId": 142,
        "observations": "Recepción completa del contenedor MSCU1234567"
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Response

Si la actualización es exitosa, el endpoint retorna `204 No Content` sin body.

### Errores

<ResponseField name="400 Bad Request">
  La recepción de compra ya ha sido cancelada y no puede actualizarse.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ninguna recepción de compra con el `id` especificado en la URL.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PurchaseReceptions.Write` requerido.
</ResponseField>
