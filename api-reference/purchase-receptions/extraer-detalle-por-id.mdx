---
title: "Obtener Detalle por ID"
api: "GET /purchase-receptions/{id}/details/{detailId}"
---

Obtén un detalle específico asociado a una recepción de compra.

<Note>
  Este endpoint requiere el scope **`PurchaseReceptions.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la recepción de compra.
</ParamField>

<ParamField path="detailId" type="integer" required>
  Identificador único del detalle a consultar.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/purchase-receptions/512/details/1" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID" \
  --header "Content-Type: application/json"
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/purchase-receptions/512/details/1", {
  method: "GET",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
    "Content-Type": "application/json",
  },
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/purchase-receptions/512/details/1",
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Response fields

<ResponseField name="id" type="integer">
  Identificador único del detalle.
</ResponseField>

<ResponseField name="product" type="object">
  Producto recibido.

  <Expandable title="Ver propiedades">
    <ResponseField name="id" type="integer">
      Identificador del producto.
    </ResponseField>

    <ResponseField name="name" type="string">
      Nombre del producto.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="productPackaging" type="object">
  Empaque del producto. `null` si no fue especificado.

  <Expandable title="Ver propiedades">
    <ResponseField name="id" type="integer">
      Identificador del empaque.
    </ResponseField>

    <ResponseField name="name" type="string">
      Nombre del empaque.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="packagingQuantity" type="decimal">
  Cantidad de empaques recibidos.
</ResponseField>

<ResponseField name="quantity" type="decimal">
  Cantidad de unidades recibidas.
</ResponseField>

<ResponseField name="purchaseOrderDetail" type="object">
  Detalle de la orden de compra contra el cual se recibió el producto. `null` si la recepción no está asociada a una orden de compra.

  <Expandable title="Ver propiedades">
    <ResponseField name="id" type="integer">
      Identificador del detalle de la orden de compra.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="insertedBy" type="string">
  Usuario que creó el registro.
</ResponseField>

<ResponseField name="insertedDate" type="string">
  Fecha de creación en formato ISO 8601.
</ResponseField>

<ResponseField name="updatedBy" type="string">
  Usuario que actualizó el registro por última vez. `null` si no ha sido actualizado.
</ResponseField>

<ResponseField name="updatedDate" type="string">
  Fecha de la última actualización en formato ISO 8601. `null` si no ha sido actualizado.
</ResponseField>

### Errores

<ResponseField name="404 Not Found">
  No existe ninguna recepción de compra con el `id` especificado, o el `detailId` no pertenece a la recepción.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PurchaseReceptions.Read` requerido.
</ResponseField>
