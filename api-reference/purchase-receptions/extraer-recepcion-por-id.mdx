---
title: "Obtener Recepción de Compra Por ID"
sidebarTitle: "Obtener por ID"
description: "Permite extraer una recepción de compra en específico mediante REST API"
api: "GET /purchase-receptions/{id}"
---

Obtén una recepción de compra por ID en la empresa.

<Note>
  Este endpoint requiere el scope **`PurchaseReceptions.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la recepción de compra.
</ParamField>

### Query parameters

<ParamField query="include" type="string[]">
  Secciones adicionales a incluir en la respuesta. Valores aceptados:

  - `Details`
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/purchase-receptions/512?include=Details" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch(
  "https://api.primenetcloud.com/v1/purchase-receptions/512?include=Details",
  {
    method: "GET",
    headers: {
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID"
    },
  }
);
const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/purchase-receptions/512?include=Details",
    headers={
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID"
    }
)
print(response.json())
```

</CodeGroup>

### Response fields

<ResponseField name="id" type="integer">
  Identificador único de la recepción de compra.
</ResponseField>

<ResponseField name="number" type="integer">
  Número de la recepción de compra.
</ResponseField>

<ResponseField name="date" type="date">
  Fecha de la recepción de compra.
</ResponseField>

<ResponseField name="purchaseOrder" type="object">
  Orden de compra asociada a la recepción. `null` si no está asociada a ninguna orden.

  <Expandable title="propiedades">
    <ResponseField name="id" type="integer">
      Identificador de la orden de compra.
    </ResponseField>

    <ResponseField name="journalNumber" type="integer">
      Número de comprobante contable de la orden de compra.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vendor" type="object">
  Vendor asociado a la recepción de compra. `null` si no fue especificado.

  <Expandable title="propiedades">
    <ResponseField name="id" type="integer">
      Identificador del vendor.
    </ResponseField>

    <ResponseField name="name" type="string">
      Nombre del vendor.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="observations" type="string">
  Observaciones de la recepción de compra.
</ResponseField>

<ResponseField name="insertedBy" type="string">
  Usuario que creó el registro.
</ResponseField>

<ResponseField name="insertedDate" type="string">
  Fecha y hora de creación del registro, en formato ISO 8601.
</ResponseField>

<ResponseField name="updatedBy" type="string">
  Usuario que realizó la última actualización del registro. `null` si no ha sido actualizado.
</ResponseField>

<ResponseField name="updatedDate" type="string">
  Fecha y hora de la última actualización, en formato ISO 8601. `null` si no ha sido actualizado.
</ResponseField>

<ResponseField name="cancelledBy" type="string">
  Usuario que canceló la recepción de compra. `null` si no ha sido cancelada.
</ResponseField>

<ResponseField name="cancelledDate" type="string">
  Fecha y hora de cancelación, en formato ISO 8601. `null` si no ha sido cancelada.
</ResponseField>

<ResponseField name="cancelledReason" type="string">
  Razón de la cancelación. `null` si no ha sido cancelada.
</ResponseField>

<ResponseField name="status" type="object">
  Estatus de la recepción de compra.

  <Expandable title="propiedades">
    <ResponseField name="id" type="integer">
      Identificador del estatus.

      Valores posibles:
      - `New`
      - `Deleted`
    </ResponseField>

    <ResponseField name="name" type="string">
      Nombre traducido del estatus.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="details" type="array">
  Detalles (líneas) de la recepción de compra. Solo se incluye si se solicita mediante `include=Details`.

  <Expandable title="detalle">
    <ResponseField name="id" type="integer">
      Identificador único del detalle.
    </ResponseField>

    <ResponseField name="product" type="object">
      Producto recibido.

      <Expandable title="propiedades">
        <ResponseField name="id" type="integer">
          Identificador del producto.
        </ResponseField>

        <ResponseField name="name" type="string">
          Nombre del producto.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="productPackaging" type="object">
      Empaque del producto. `null` si no fue especificado.

      <Expandable title="propiedades">
        <ResponseField name="id" type="integer">
          Identificador del empaque.
        </ResponseField>

        <ResponseField name="name" type="string">
          Nombre del empaque.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="packagingQuantity" type="decimal">
      Cantidad de empaques recibidos.
    </ResponseField>

    <ResponseField name="quantity" type="decimal">
      Cantidad de unidades recibidas.
    </ResponseField>

    <ResponseField name="purchaseOrderDetail" type="object">
      Detalle de la orden de compra contra el cual se recibió el producto. `null` si la recepción no está asociada a una orden de compra.

      <Expandable title="propiedades">
        <ResponseField name="id" type="integer">
          Identificador del detalle de la orden de compra.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="insertedBy" type="string">
      Usuario que creó el registro.
    </ResponseField>

    <ResponseField name="insertedDate" type="string">
      Fecha de creación en formato ISO 8601.
    </ResponseField>

    <ResponseField name="updatedBy" type="string">
      Usuario que actualizó el registro por última vez. `null` si no ha sido actualizado.
    </ResponseField>

    <ResponseField name="updatedDate" type="string">
      Fecha de la última actualización en formato ISO 8601. `null` si no ha sido actualizado.
    </ResponseField>
  </Expandable>
</ResponseField>

### Errores

<ResponseField name="404 Not Found">
  No existe ninguna recepción de compra con el `id` especificado en la URL.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PurchaseReceptions.Read` requerido.
</ResponseField>
