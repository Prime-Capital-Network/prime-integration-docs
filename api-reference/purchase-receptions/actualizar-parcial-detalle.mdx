---
title: "Actualizar Parcial Detalle"
api: "PATCH /purchase-receptions/{id}/details/{detailId}"
---

Actualiza un detalle parcialmente para una recepción de compra específica.

<Note>
  Este endpoint requiere el scope **`PurchaseReceptions.Write`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la recepción de compra a la que pertenece el detalle.
</ParamField>

<ParamField path="detailId" type="integer" required>
  Identificador único del detalle a actualizar.
</ParamField>

### Body parameters

<ParamField body="productId" type="integer">
  Identificador del producto recibido.
</ParamField>

<ParamField body="quantity" type="decimal">
  Cantidad de unidades recibidas.
</ParamField>

<ParamField body="productPackagingId" type="integer">
  Identificador del empaque del producto.
</ParamField>

<ParamField body="packagingQuantity" type="decimal">
  Cantidad de empaques recibidos. Debe ser mayor que cero.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request PATCH \
  --url "https://api.primenetcloud.com/v1/purchase-receptions/512/details/1" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID" \
  --header "Content-Type: application/merge-patch+json" \
  --data '{
    "quantity": 750,
    "packagingQuantity": 18.75
  }'
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/purchase-receptions/512/details/1", {
  method: "PATCH",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
    "Content-Type": "application/merge-patch+json",
  },
  body: JSON.stringify({
    quantity: 750,
    packagingQuantity: 18.75
  }),
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.patch(
    "https://api.primenetcloud.com/v1/purchase-receptions/512/details/1",
    json={
        "quantity": 750,
        "packagingQuantity": 18.75
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
        "Content-Type": "application/merge-patch+json"
    },
)

print(response.json())
```

</CodeGroup>

### Response

Si la actualización es exitosa, el endpoint retorna `204 No Content` sin body.

### Errores

<ResponseField name="400 Bad Request">
  La recepción de compra ya ha sido cancelada y no puede actualizarse.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ninguna recepción de compra con el `id` especificado en la URL, o el `detailId` no pertenece a la recepción.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PurchaseReceptions.Write` requerido.
</ResponseField>

<ResponseField name="415 Unsupported Media Type">
  La solicitud no incluye el header `Content-Type` como `application/merge-patch+json`.
</ResponseField>
