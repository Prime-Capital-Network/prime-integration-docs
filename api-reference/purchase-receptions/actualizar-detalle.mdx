---
title: "Actualizar Detalle"
api: "PUT /purchase-receptions/{id}/details/{detailId}"
---

Actualiza un detalle para una recepción de compra específica.

<Note>
  Este endpoint requiere el scope **`PurchaseReceptions.Write`**.
</Note>

<Warning>
  Este es un reemplazo completo del recurso (PUT). Todos los campos enviados en el body sobrescribirán el estado actual del detalle. Para cambios parciales, verificar la sección [Actualizar Parcial Detalle](/api-reference/purchase-receptions/actualizar-parcial-detalle).
</Warning>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la recepción de compra a la que pertenece el detalle.
</ParamField>

<ParamField path="detailId" type="integer" required>
  Identificador único del detalle a actualizar.
</ParamField>

### Body parameters

<ParamField body="productId" type="integer" required>
  Identificador del producto recibido.
</ParamField>

<ParamField body="quantity" type="decimal" required>
  Cantidad de unidades recibidas.
</ParamField>

<ParamField body="productPackagingId" type="integer">
  Identificador del empaque del producto.
</ParamField>

<ParamField body="packagingQuantity" type="decimal" required>
  Cantidad de empaques recibidos. Debe ser mayor que cero.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request PUT \
  --url "https://api.primenetcloud.com/v1/purchase-receptions/512/details/1" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID" \
  --header "Content-Type: application/json" \
  --data '{
    "productId": 88,
    "quantity": 750,
    "productPackagingId": 10,
    "packagingQuantity": 18.75
  }'
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/purchase-receptions/512/details/1", {

```

```python Python
import requests

response = requests.put(
    "https://api.primenetcloud.com/v1/purchase-receptions/512/details/1",

```

</CodeGroup>

### Response

Si la actualización es exitosa, el endpoint retorna `204 No Content` sin body.

### Errores

<ResponseField name="400 Bad Request">
  La recepción de compra ya ha sido cancelada y no puede actualizarse.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ninguna recepción de compra con el `id` especificado, o el `detailId` no pertenece a la recepción.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PurchaseReceptions.Write` requerido.
</ResponseField>
