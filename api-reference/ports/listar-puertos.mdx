Obtén una lista paginada de puertos.

<Note>
  Este endpoint requiere el scope **`Ports.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Query parameters

<ParamField query="country_id" type="string" required>
  Código ISO 3166-1 alfa-2 del país al cual pertenecen los puertos.
</ParamField>

<ParamField query="Type" type="string" required>
  Tipo de puerto. Valores aceptados:

  - `Sea`
  - `Air`
  - `Rail`
</ParamField>

<ParamField query="filter_by" type="string">
  Valores aceptados:

  - `Active`
</ParamField>

<ParamField query="skip" default="0" type="integer">
  Número de registros a omitir desde el inicio de los resultados. Utilízado junto con `take` para paginar los resultados.
</ParamField>

<ParamField query="take" default="20" type="integer">
  Número de registros a retornar. Por defecto `20`, máximo `100`.
</ParamField>

<ParamField query="Id" type="StringSearchFilter">
  Filtra por el identificador del puerto.
</ParamField>

<ParamField query="Name" type="StringSearchFilter">
  Filtra por el nombre del puerto.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/ports?country_id=DO&Type=Sea&take=20" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch(
  "https://api.primenetcloud.com/v1/ports?country_id=DO&Type=Sea&take=20",
  {
    method: "GET",
    headers: {
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID",
    },
  }
);

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/ports",
    params={
        "country_id": "DO",
        "Type": "Sea",
        "take": 20,
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Example response

```json
{
  "totalCount": 1,
  "data": [
    {
      "id": "DOCAU",
      "name": "Puerto Caucedo",
      "isActive": true
    }
  ]
}
```

### Response fields

<ResponseField name="totalCount" type="integer">
  Total de registros.
</ResponseField>

<ResponseField name="data" type="array">
  Lista de objetos Port.

  <Expandable title="Port">
    <ResponseField name="id" type="string">
      Identificador único del puerto.
    </ResponseField>

    <ResponseField name="name" type="string">
      Nombre del puerto.
    </ResponseField>

    <ResponseField name="isActive" type="boolean">
      Indica si el puerto está activo.
    </ResponseField>
  </Expandable>
</ResponseField>

### Errores

<ResponseField name="400 Bad Request">
  Falta el parámetro `country_id` o `Type`, o `country_id` no es un código de país válido de 2 caracteres.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `Ports.Read` requerido.
</ResponseField>
