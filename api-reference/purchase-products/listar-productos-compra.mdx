---
title: "Listar"
api: "GET /purchase-products"
---

Obtén una lista paginada de productos de compra en la empresa.

<Note>
  Este endpoint requiere el scope **`PurchaseProducts.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Query parameters

<ParamField query="filter_by" type="string">
  Filtra los productos de compra. Valores aceptados:

  - `Active`
</ParamField>

<ParamField query="skip" default="0" type="integer">
  Número de registros a omitir desde el inicio de los resultados. Utilízado junto con `take` para paginar los resultados.
</ParamField>

<ParamField query="take" default="20" type="integer">
  Número de registros a retornar. Por defecto `20`, máximo `100`.
</ParamField>

<ParamField query="Name" type="StringSearchFilter">
  Filtra por el nombre del producto de compra.
</ParamField>

<ParamField query="CategoryName" type="StringSearchFilter">
  Filtra por el nombre de la categoría del producto de compra.
</ParamField>

<ParamField query="ManufacturerName" type="StringSearchFilter">
  Filtra por el nombre del fabricante del producto de compra.
</ParamField>

<ParamField query="BrandName" type="StringSearchFilter">
  Filtra por el nombre de la marca del producto de compra.
</ParamField>

<ParamField query="PackagingName" type="StringSearchFilter">
  Filtra por el nombre del empaque del producto de compra.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/purchase-products?filter_by=Active&skip=0&take=20" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch(
  "https://api.primenetcloud.com/v1/purchase-products?filter_by=Active&skip=0&take=20",
  {
    method: "GET",
    headers: {
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID"
    },
  }
);

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/purchase-products",
    params={
        "filter_by": "Active",
        "skip": 0,
        "take": 20,
    },
    headers={
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID"
    }
)

print(response.json())
```

</CodeGroup>

### Response fields

<ResponseField name="totalCount" type="integer">
  Total de registros.
</ResponseField>

<ResponseField name="data" type="array">
  Lista de objetos PurchaseProduct.

  <Expandable title="PurchaseProduct">
    <ResponseField name="id" type="integer">
      Identificador único del producto de compra.
    </ResponseField>

    <ResponseField name="name" type="string">
      Nombre del producto de compra.
    </ResponseField>

    <ResponseField name="goodServiceApplicability" type="object">
      Aplicabilidad del producto de compra.

      <Expandable title="propiedades">
        <ResponseField name="id" type="integer">
          Identificador de la aplicabilidad.

          Valores posibles:
          - `NotApplicable`
          - `Product`
          - `Service`
        </ResponseField>

        <ResponseField name="name" type="string">
          Nombre traducido de la aplicabilidad.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="categoryName" type="string">
      Nombre de la categoría del producto de compra.
    </ResponseField>

    <ResponseField name="manufacturerName" type="string">
      Nombre del fabricante del producto de compra. `null` si no aplica.
    </ResponseField>

    <ResponseField name="brandName" type="string">
      Nombre de la marca del producto de compra. `null` si no aplica.
    </ResponseField>

    <ResponseField name="packagingName" type="string">
      Nombre del empaque del producto de compra. `null` si no aplica.
    </ResponseField>

    <ResponseField name="isActive" type="boolean">
      Indica si el producto de compra está activo.
    </ResponseField>
  </Expandable>
</ResponseField>
