---
title: "Actualizar Parcial"
sidebarTitle: "Actualizar Parcial"
api: "PATCH /purchase-products/{id}"
---

Actualiza los datos parcialmente de un producto de compra en la empresa.

<Note>
  Este endpoint requiere el scope **`PurchaseProducts.Write`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único del producto de compra a actualizar.
</ParamField>

### Body parameters

<ParamField body="name" type="string">
  Nombre del producto de compra. Máximo 200 caracteres.
</ParamField>

<ParamField body="goodServiceApplicability" type="string">
  Aplicabilidad del producto de compra. Valores aceptados:

  - `NotApplicable`
  - `Product`
  - `Service`
</ParamField>

<ParamField body="categoryId" type="integer">
  Identificador de la categoría del producto de compra.
</ParamField>

<ParamField body="manufacturerId" type="integer">
  Identificador del fabricante del producto de compra.

  - Requerido si `brandId` está presente.
</ParamField>

<ParamField body="brandId" type="integer">
  Identificador de la marca del producto de compra.
</ParamField>

<ParamField body="packagingId" type="integer">
  Identificador del empaque del producto de compra.
</ParamField>

<ParamField body="taxRate" type="decimal">
  Tasa de impuesto aplicada al producto de compra. Debe ser mayor o igual a cero.
</ParamField>

<ParamField body="isActive" type="boolean">
  Indica si el producto de compra está activo.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request PATCH \
  --url "https://api.primenetcloud.com/v1/purchase-products/412" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID" \
  --header "Content-Type: application/merge-patch+json" \
  --data '{
    "taxRate": 16,
    "isActive": false
  }'
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/purchase-products/412", {
  method: "PATCH",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
    "Content-Type": "application/merge-patch+json",
  },
  body: JSON.stringify({
    taxRate: 16,
    isActive: false
  }),
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.patch(
    "https://api.primenetcloud.com/v1/purchase-products/412",
    json={
        "taxRate": 16,
        "isActive": False
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
        "Content-Type": "application/merge-patch+json"
    },
)

print(response.json())
```

</CodeGroup>

### Response

Si la actualización es exitosa, el endpoint retorna `204 No Content` sin body.

### Errores

<ResponseField name="404 Not Found">
  No existe ningún producto de compra con el `id` especificado en la URL.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PurchaseProducts.Write` requerido.
</ResponseField>

<ResponseField name="415 Unsupported Media Type">
  La solicitud no incluye el header `Content-Type` como `application/merge-patch+json`.
</ResponseField>
