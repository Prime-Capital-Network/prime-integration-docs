---
title: "Obtener Estatus Aduanero Por ID"
sidebarTitle: "Obtener por ID"
description: "Permite extraer un estatus aduanero en específico mediante REST API"
api: "GET /custom-statuses/{id}"
---

Obtén un estatus aduanero por ID en la empresa.

<Note>
  Este endpoint requiere el scope **`CustomStatuses.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único del estatus aduanero.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/custom-statuses/1" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch(
  "https://api.primenetcloud.com/v1/custom-statuses/1",
  {
    method: "GET",
    headers: {
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID",
    },
  }
);

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/custom-statuses/1",
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Example response

```json
{
  "id": 1,
  "name": "En Tránsito",
  "insertedBy": "string",
  "insertedDate": "2026-07-01T08:00:00.000Z",
  "updatedBy": "string",
  "updatedDate": "2026-07-03T11:00:00.000Z",
  "isActive": true
}
```

### Response fields

<ResponseField name="id" type="integer">
  Identificador único del estatus aduanero.
</ResponseField>

<ResponseField name="name" type="string">
  Nombre del estatus aduanero.
</ResponseField>

<ResponseField name="insertedBy" type="string">
  Usuario que creó el registro.
</ResponseField>

<ResponseField name="insertedDate" type="string">
  Fecha y hora de creación del registro, en formato ISO 8601.
</ResponseField>

<ResponseField name="updatedBy" type="string">
  Usuario que realizó la última actualización del registro.
</ResponseField>

<ResponseField name="updatedDate" type="string">
  Fecha y hora de la última actualización, en formato ISO 8601.
</ResponseField>

<ResponseField name="isActive" type="boolean">
  Indica si el estatus aduanero está activo.
</ResponseField>

### Errores

<ResponseField name="404 Not Found">
  No existe ningún estatus aduanero con el `id` especificado en la URL.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `CustomStatuses.Read` requerido.
</ResponseField>
