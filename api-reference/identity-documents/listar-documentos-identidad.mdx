Obtén una lista de documentos de identidad (por ejemplo, Cédula, RNC, Pasaporte) en la empresa.

<Note>
  Este endpoint requiere el scope **`IdentityDocuments.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Query parameters

<ParamField query="filter_by" type="string">
  Valores aceptados:

  - `Active`
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/identity-documents?filter_by=Active" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch(
  "https://api.primenetcloud.com/v1/identity-documents?filter_by=Active",
  {
    method: "GET",
    headers: {
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID",
    },
  }
);

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/identity-documents",
    params={
        "filter_by": "Active",
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Response fields

<ResponseField name="id" type="integer">
  Identificador único del documento de identidad.
</ResponseField>

<ResponseField name="name" type="string">
  Nombre del documento de identidad, según el idioma de la solicitud.
</ResponseField>

<ResponseField name="length" type="integer">
  Longitud esperada del número de documento.
</ResponseField>

<ResponseField name="fieldType" type="object">
  Tipo de dato aceptado por el número de documento.

  <Expandable title="propiedades">
    <ResponseField name="id" type="string">
      Identificador del tipo de dato. Valores posibles: `Alphanumeric`, `Numeric`.
    </ResponseField>

    <ResponseField name="name" type="string">
      Nombre traducido del tipo de dato.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="isActive" type="boolean">
  Indica si el documento de identidad está activo.
</ResponseField>

### Errores

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `IdentityDocuments.Read` requerido.
</ResponseField>
