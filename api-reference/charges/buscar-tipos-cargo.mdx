api: "GET /charges/types/search"
---

Busca tipos de cargo por nombre. Este es un catálogo distinto al recurso de cargos, utilizado como referencia al crear o filtrar cargos.

<Note>
  Este endpoint requiere el scope **`ChargeTypes.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Query parameters

<ParamField query="value" type="string">
  Texto libre para buscar por nombre del tipo de cargo.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/charges/types/search?value=Flete" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch(
  "https://api.primenetcloud.com/v1/charges/types/search?value=Flete",
  {
    method: "GET",
    headers: {
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID",
    },
  }
);

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/charges/types/search",
    params={
        "value": "Flete",
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Example response

```json
[
  {
    "id": 1,
    "name": "Flete"
  },
  {
    "id": 2,
    "name": "Manejo"
  }
]
```

### Response fields

<ResponseField name="id" type="integer">
  Identificador único del tipo de cargo.
</ResponseField>

<ResponseField name="name" type="string">
  Nombre del tipo de cargo.
</ResponseField>

### Errores

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `ChargeTypes.Read` requerido.
</ResponseField>
