Obtén una lista de términos de pago en la empresa.

<Note>
  Este endpoint requiere el scope **`PaymentTerms.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Query parameters

<ParamField query="filter_by" type="string">
  Valores aceptados:

  - `Active`
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/payment-terms?filter_by=Active" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch(
  "https://api.primenetcloud.com/v1/payment-terms?filter_by=Active",
  {
    method: "GET",
    headers: {
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID",
    },
  }
);

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/payment-terms",
    params={
        "filter_by": "Active",
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Response fields

<ResponseField name="id" type="integer">
  Identificador único del término de pago.
</ResponseField>

<ResponseField name="name" type="string">
  Nombre del término de pago, según el idioma de la solicitud.
</ResponseField>

<ResponseField name="type" type="object">
  Tipo del término de pago.

  <Expandable title="propiedades">
    <ResponseField name="id" type="string">
      Identificador del tipo. Valores posibles: `Credit`, `Cashdown`.
    </ResponseField>

    <ResponseField name="name" type="string">
      Nombre traducido del tipo.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="expirationDays" type="integer">
  Cantidad de días de vencimiento del término de pago.
</ResponseField>

<ResponseField name="isActive" type="boolean">
  Indica si el término de pago está activo.
</ResponseField>

### Errores

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PaymentTerms.Read` requerido.
</ResponseField>
