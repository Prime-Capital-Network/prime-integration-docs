---
title: "Crear Detalle"
api: "POST /reimbursement-liabilities/{id}/details"
---

Crea un nuevo detalle para un reembolso específico.

<Note>
  Este endpoint requiere el scope **`ReimbursementLiabilities.Write`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único del reembolso al que se agregará el detalle.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request POST \
  --url "https://api.primenetcloud.com/v1/reimbursement-liabilities/1054/details" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID" \
  --header "Content-Type: application/json" \
  --data '{
    "chargeId": 5,
    "description": "Flete marítimo principal",
    "quantity": 1,
    "price": 1500,
    "operationId": 5321,
    "operationCategory": "Shipment"
  }'
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/reimbursement-liabilities/1054/details", {
  method: "POST",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    chargeId: 5,
    description: "Flete marítimo principal",
    quantity: 1,
    price: 1500,
    operationId: 5321,
    operationCategory: "Shipment"
  }),
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.post(
    "https://api.primenetcloud.com/v1/reimbursement-liabilities/1054/details",
    json={
        "chargeId": 5,
        "description": "Flete marítimo principal",
        "quantity": 1,
        "price": 1500,
        "operationId": 5321,
        "operationCategory": "Shipment"
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Response fields

<ResponseField name="id" type="integer">
  Identificador único del detalle de reembolso creado.
</ResponseField>

### Errores

<ResponseField name="400 Bad Request">
  La solicitud será rechazada si el reembolso ya ha sido posteado (campo `status` como `Posted`). El reembolso no puede ser modificado en este estado.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `ReimbursementLiabilities.Write` requerido.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ningún reembolso con el `id` especificado en la URL.
</ResponseField>
