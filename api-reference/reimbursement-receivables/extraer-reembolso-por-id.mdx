---
title: "Obtener reembolso por ID"
sidebarTitle: "Obtener por ID"
description: "Permite extraer un reembolso por cobrar en específico mediante REST API"
api: "GET /reimbursement-receivables/{id}"
---

Obtén un reembolso por cobrar por ID en la empresa.

<Note>
  Este endpoint requiere el scope **`ReimbursementReceivables.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único del reembolso.
</ParamField>

### Query parameters

<ParamField query="include" type="string[]">
  Secciones adicionales a incluir en la respuesta. Valores aceptados:

  - `Details`
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/reimbursement-receivables/1187?include=Details" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/reimbursement-receivables/1187?include=Details", {
  method: "GET",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
  },
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/reimbursement-receivables/1187",
    params={
        "include": "Details",
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

  Identificador único del reembolso.
</ResponseField>

<ResponseField name="journalNumber" type="integer">
  Número de comprobante contable del reembolso.
</ResponseField>

<ResponseField name="transactionNumber" type="integer">
  Número de transacción del reembolso.
</ResponseField>

<ResponseField name="date" type="date">
  Fecha del reembolso.
</ResponseField>

<ResponseField name="dueDate" type="datetime">
  Fecha de vencimiento, calculada a partir de la fecha y del término de pago.
</ResponseField>

<ResponseField name="proformaNumber" type="integer">
  Número del reembolso preliminar del que proviene. `null` si no proviene de uno.

</ResponseField>

### Errores

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `ReimbursementReceivables.Read` requerido.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ningún reembolso con el `id` especificado en la URL, o es un reembolso preliminar (proforma).
</ResponseField>
