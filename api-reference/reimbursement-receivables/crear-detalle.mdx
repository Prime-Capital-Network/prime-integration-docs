---
title: "Crear Detalle"
api: "POST /reimbursement-receivables/{id}/details"
---

Agrega un detalle a un reembolso por cobrar. El sistema recalcula automáticamente los totales y las cuentas contables del reembolso.

<Note>
  Este endpoint requiere el scope **`ReimbursementReceivables.Write`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único del reembolso al que se agregará el detalle.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request POST \
  --url "https://api.primenetcloud.com/v1/reimbursement-receivables/1187/details" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID" \
  --header "Content-Type: application/json" \
  --data '{
    "chargeId": 112,
    "chargeDescription": "Gastos de muelle Puerto de Haina",
    "quantity": 1,
    "price": 12500,
    "operationCategory": "Shipment",
    "operationId": 5321,
    "departmentId": 3
  }'
```

        "operationCategory": "Shipment",

### Errores

<ResponseField name="400 Bad Request">
  La solicitud no cumple alguna de las reglas de los campos (por ejemplo, el cargo no aplica para reembolsos o la operación no existe).
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `ReimbursementReceivables.Write` requerido.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ningún reembolso con el `id` especificado en la URL, o es un reembolso preliminar (proforma).
</ResponseField>
