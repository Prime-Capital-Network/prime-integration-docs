---
title: "Actualizar Parcial Detalle"
api: "PATCH /reimbursement-receivables/{id}/details/{detailId}"
---

Actualiza solo los campos enviados de un detalle de un reembolso por cobrar, siguiendo el formato [JSON Merge Patch](https://datatracker.ietf.org/doc/html/rfc7396): los campos omitidos conservan su valor actual y los enviados como `null` se limpian.

<Note>
  Este endpoint requiere el scope **`ReimbursementReceivables.Write`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

<ParamField header="Content-Type" type="string" required>
  Debe ser `application/merge-patch+json`.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único del reembolso.
</ParamField>

<ParamField path="detailId" type="integer" required>
  Identificador único del detalle a actualizar.
</ParamField>

### Body parameters

Acepta los mismos campos que [Actualizar Detalle](/api-reference/reimbursement-receivables/actualizar-detalle), todos opcionales. El resultado de aplicar el parche se valida con las mismas reglas.

<ParamField body="chargeId" type="integer">
  Identificador del cargo.

  - Debe ser un cargo que aplique para reembolsos (`appliesForReimbursement` como `true`) y con una cuenta de reembolsos por cobrar asignada.
</ParamField>

<ParamField body="chargeDescription" type="string">
  Descripción del cargo en el reembolso. Máximo 120 caracteres. Si no se envía, se usa el nombre del cargo.
</ParamField>

<ParamField body="chargeDetails" type="string">
  Detalle adicional del cargo. Máximo 250 caracteres.
</ParamField>

<ParamField body="calculationTypeId" type="string">
  Identificador del tipo de cálculo. Máximo 3 caracteres.
</ParamField>

<ParamField body="quantity" type="decimal">
  Cantidad. Debe ser mayor que cero.
</ParamField>

<ParamField body="price" type="decimal">
  Precio unitario. Debe ser mayor que cero.
</ParamField>

<ParamField body="operationCategory" type="string">
  Categoría de la operación logística asociada. Requerido si `operationId` está presente. Valores aceptados:

  - `Shipment` (Embarque)
  - `CustomManagement` (Aduanas)
  - `Additional` (Misceláneos)
  - `InlandFreight` (Transporte Terrestre)
</ParamField>

<ParamField body="operationId" type="integer">
  Identificador de la operación logística asociada. Requerido si `operationCategory` está presente.
</ParamField>

<ParamField body="masterId" type="integer">
  Identificador del master asociado.
</ParamField>

<ParamField body="departmentId" type="integer">
  Identificador del departamento. Debe ser una dimensión de tipo departamento.
</ParamField>

<ParamField body="costCenterId" type="integer">
  Identificador del centro de costo. Debe ser una dimensión de tipo centro de costo.
</ParamField>

<ParamField body="projectId" type="integer">
  Identificador del proyecto. Debe ser una dimensión de tipo proyecto.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request PATCH \
  --url "https://api.primenetcloud.com/v1/reimbursement-receivables/1187/details/4410" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID" \
  --header "Content-Type: application/merge-patch+json" \
  --data '{
    "price": 13750,
    "chargeDetails": "Incluye almacenaje de 2 días"
  }'
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/reimbursement-receivables/1187/details/4410", {
  method: "PATCH",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
    "Content-Type": "application/merge-patch+json",
  },
  body: JSON.stringify({
    price: 13750,
    chargeDetails: "Incluye almacenaje de 2 días"
  }),
});

console.log(response.status);
```

```python Python
import json
import requests

response = requests.patch(
    "https://api.primenetcloud.com/v1/reimbursement-receivables/1187/details/4410",
    data=json.dumps({
        "price": 13750,
        "chargeDetails": "Incluye almacenaje de 2 días"
    }),
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
        "Content-Type": "application/merge-patch+json",
    },
)

print(response.status_code)
```

</CodeGroup>

### Response

Si la actualización es exitosa, el endpoint retorna `204 No Content` sin body.

### Errores

<ResponseField name="400 Bad Request">
  La solicitud no cumple alguna de las reglas de los campos (por ejemplo, el cargo no aplica para reembolsos o la operación no existe).
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `ReimbursementReceivables.Write` requerido.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ningún reembolso con el `id` especificado (o es un reembolso preliminar), o el `detailId` no pertenece al reembolso.
</ResponseField>

<ResponseField name="415 Unsupported Media Type">
  La solicitud no incluye el header `Content-Type` como `application/merge-patch+json`.
</ResponseField>
