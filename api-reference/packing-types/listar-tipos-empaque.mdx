Obtén una lista de tipos de empaque en la empresa.

<Note>
  Este endpoint requiere el scope **`PackingTypes.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Query parameters

<ParamField query="filter_by" type="string">
  Valores aceptados:

  - `Active`
</ParamField>

<ParamField query="SpanishName" type="StringSearchFilter">
  Filtra por el nombre en español del tipo de empaque.
</ParamField>

<ParamField query="EnglishName" type="StringSearchFilter">
  Filtra por el nombre en inglés del tipo de empaque.
</ParamField>

<ParamField query="SIGACode" type="StringSearchFilter">
  Filtra por el código SIGA (aduanas) del tipo de empaque.
</ParamField>

<ParamField query="Abbreviation" type="StringSearchFilter">
  Filtra por la abreviatura del tipo de empaque.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/packing-types?filter_by=Active" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch(
  "https://api.primenetcloud.com/v1/packing-types?filter_by=Active",
  {
    method: "GET",
    headers: {
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID",
    },
  }
);

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/packing-types",
    params={
        "filter_by": "Active",
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Example response

```json
[
  {
    "id": 1,
    "spanishName": "Caja",
    "englishName": "Box",
    "sigaCode": "CJ",
    "abbreviation": "CJA",
    "isActive": true
  }
]
```

### Response fields

<ResponseField name="id" type="integer">
  Identificador único del tipo de empaque.
</ResponseField>

<ResponseField name="spanishName" type="string">
  Nombre del tipo de empaque en español.
</ResponseField>

<ResponseField name="englishName" type="string">
  Nombre del tipo de empaque en inglés.
</ResponseField>

<ResponseField name="sigaCode" type="string">
  Código SIGA (aduanas) del tipo de empaque.
</ResponseField>

<ResponseField name="abbreviation" type="string">
  Abreviatura del tipo de empaque.
</ResponseField>

<ResponseField name="isActive" type="boolean">
  Indica si el tipo de empaque está activo.
</ResponseField>

### Errores

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PackingTypes.Read` requerido.
</ResponseField>
