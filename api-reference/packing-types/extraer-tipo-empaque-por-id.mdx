---
title: "Obtener Tipo de Empaque Por ID"
sidebarTitle: "Obtener por ID"
description: "Permite extraer un tipo de empaque en específico mediante REST API"
api: "GET /packing-types/{id}"
---

Obtén un tipo de empaque por ID en la empresa.

<Note>
  Este endpoint requiere el scope **`PackingTypes.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único del tipo de empaque.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/packing-types/1" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch(
  "https://api.primenetcloud.com/v1/packing-types/1",
  {
    method: "GET",
    headers: {
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID",
    },
  }
);

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/packing-types/1",
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Example response

```json
{
  "id": 1,
  "spanishName": "Caja",
  "englishName": "Box",
  "sigaCode": "CJ",
  "abbreviation": "CJA",
  "insertedBy": "string",
  "insertedDate": "2026-07-01T08:00:00.000Z",
  "updatedBy": "string",
  "updatedDate": "2026-07-03T11:00:00.000Z",
  "isActive": true
}
```

### Response fields

<ResponseField name="id" type="integer">
  Identificador único del tipo de empaque.
</ResponseField>

<ResponseField name="spanishName" type="string">
  Nombre del tipo de empaque en español.
</ResponseField>

<ResponseField name="englishName" type="string">
  Nombre del tipo de empaque en inglés.
</ResponseField>

<ResponseField name="sigaCode" type="string">
  Código SIGA (aduanas) del tipo de empaque.
</ResponseField>

<ResponseField name="abbreviation" type="string">
  Abreviatura del tipo de empaque.
</ResponseField>

<ResponseField name="insertedBy" type="string">
  Usuario que creó el registro.
</ResponseField>

<ResponseField name="insertedDate" type="string">
  Fecha y hora de creación del registro, en formato ISO 8601.
</ResponseField>

<ResponseField name="updatedBy" type="string">
  Usuario que realizó la última actualización del registro.
</ResponseField>

<ResponseField name="updatedDate" type="string">
  Fecha y hora de la última actualización, en formato ISO 8601.
</ResponseField>

<ResponseField name="isActive" type="boolean">
  Indica si el tipo de empaque está activo.
</ResponseField>

### Errores

<ResponseField name="404 Not Found">
  No existe ningún tipo de empaque con el `id` especificado en la URL.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PackingTypes.Read` requerido.
</ResponseField>
