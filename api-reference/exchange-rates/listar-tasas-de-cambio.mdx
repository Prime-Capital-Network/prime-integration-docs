Obtén una lista limitada de tasas de cambio de 2 monedas.

<Note>
  Este endpoint requiere el scope **`ExchangeRates.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Query parameters

<ParamField query="BaseId" type="string" required>
  ID de la moneda base.
</ParamField>

<ParamField query="ConvertId" type="string" required>
  ID de la moneda convertida.
</ParamField>

<ParamField query="Count" type="integer">
  Cantidad a traer. Valor entre `1` y `20`. Por defecto, `5`.
</ParamField>

<ParamField query="Date" type="datetimeoffset">
  Fecha límite de búsqueda.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/currencies/rates?BaseId=USD&ConvertId=DOP&Count=5" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch(
  "https://api.primenetcloud.com/v1/currencies/rates?BaseId=USD&ConvertId=DOP&Count=5",
  {
    method: "GET",
    headers: {
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID",
    },
  }
);

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/currencies/rates",
    params={
        "BaseId": "USD",
        "ConvertId": "DOP",
        "Count": 5,
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Example response

```json
[
  {
    "date": "2026-07-24",
    "rate": 58.75
  },
  {
    "date": "2026-07-23",
    "rate": 58.7
  }
]
```

### Response fields

<ResponseField name="date" type="datetimeoffset">
  Fecha correspondiente a la tasa de cambio.
</ResponseField>

<ResponseField name="rate" type="decimal">
  Tasa de cambio entre la moneda base (`BaseId`) y la moneda convertida (`ConvertId`) en la fecha indicada.
</ResponseField>
