Actualiza los datos de una entrega de compra en la empresa.

<Note>
  Este endpoint requiere el scope **`PurchaseDeliveries.Write`**.
</Note>

<Warning>
  Este es un reemplazo completo del recurso (PUT). Todos los campos enviados en el body sobrescribirán el estado actual de la entrega. Para cambios parciales, verificar la sección [Actualizar Parcial](/api-reference/purchase-deliveries/actualizar-parcial-entregas).
</Warning>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la entrega de compra a actualizar.
</ParamField>

### Body parameters

<ParamField body="requestId" type="integer">
  Identificador de la solicitud de compra contra la cual se entrega la mercancía.

  - No puede cambiarse si la entrega ya tiene detalles vinculados a una solicitud de compra.
</ParamField>

<ParamField body="date" type="date" required>
  Fecha de la entrega de compra en formato `YYYY-MM-DD`.
</ParamField>

<ParamField body="requestedBy" type="string">
  Identificador del usuario solicitante.
</ParamField>

<ParamField body="confirmedBy" type="string">
  Identificador del usuario que confirma la entrega.

  - Al especificarse por primera vez, se registra automáticamente la fecha de confirmación (`confirmationDate`) con la fecha y hora actuales.
</ParamField>

<ParamField body="handedTo" type="string" required>
  A quién le será entregada la mercancía. Valores aceptados:

  - `Requester`
  - `ThirdPerson`
</ParamField>

<ParamField body="receiverId" type="integer">
  Identificador del receptor (tercero) que recibe la mercancía.

  - Requerido cuando `handedTo` es `ThirdPerson`.
  - No puede especificarse cuando `handedTo` es `Requester`.
</ParamField>

<ParamField body="status" type="string" required>
  Estatus de la entrega de compra. Valores aceptados:

  - `New`
  - `Confirmed`
  - `Deleted`
</ParamField>

### Response

Si la actualización es exitosa, el endpoint retorna `204 No Content` sin body.

### Errores

<ResponseField name="400 Bad Request">
  La entrega de compra ya ha sido cancelada y no puede actualizarse, alguno de los identificadores especificados no es válido, la combinación de `handedTo`/`receiverId` es inconsistente, o se intentó cambiar `requestId` teniendo detalles vinculados a una solicitud de compra.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ninguna entrega de compra con el `id` especificado en la URL.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PurchaseDeliveries.Write` requerido.
</ResponseField>
