title: "Crear"
api: "POST /purchase-deliveries"
---

Crea una nueva entrega de compra en la empresa.

<Note>
  Este endpoint requiere el scope **`PurchaseDeliveries.Write`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Body parameters

<ParamField body="requestId" type="integer">
  Identificador de la solicitud de compra contra la cual se entrega la mercancía.
</ParamField>

<ParamField body="date" type="date" required>
  Fecha de la entrega de compra en formato `YYYY-MM-DD`.
</ParamField>

<ParamField body="requestedBy" type="string">
  Identificador del usuario solicitante.
</ParamField>

<ParamField body="handedTo" type="string" required>
  A quién le será entregada la mercancía. Valores aceptados:

  - `Requester`
  - `ThirdPerson`
</ParamField>

<ParamField body="receiverId" type="integer">
  Identificador del receptor (tercero) que recibe la mercancía.

  - Requerido cuando `handedTo` es `ThirdPerson`.
  - No puede especificarse cuando `handedTo` es `Requester`.
</ParamField>

  --header "Content-Type: application/json" \

### Response fields

<ResponseField name="id" type="integer">
  Identificador único de la entrega de compra creada.
</ResponseField>

### Errores

<ResponseField name="400 Bad Request">
  Alguno de los identificadores especificados (`requestId`, `requestedBy`, `receiverId`, `productId`, `requestDetailId`) no es válido, o la combinación de `handedTo`/`receiverId` es inconsistente.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PurchaseDeliveries.Write` requerido.
</ResponseField>
