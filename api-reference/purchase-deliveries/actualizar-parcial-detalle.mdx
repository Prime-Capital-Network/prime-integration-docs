---
title: "Actualizar Parcial Detalle"
sidebarTitle: "Actualizar Parcial"
api: "PATCH /purchase-deliveries/{id}/details/{detailId}"
---

Actualiza un detalle parcialmente para una entrega de compra específica.

<Note>
  Este endpoint requiere el scope **`PurchaseDeliveries.Write`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la entrega de compra a la que pertenece el detalle.
</ParamField>

<ParamField path="detailId" type="integer" required>
  Identificador único del detalle a actualizar.
</ParamField>

### Body parameters

<ParamField body="productId" type="integer">
  Identificador del producto entregado.
</ParamField>

<ParamField body="quantity" type="decimal">
  Cantidad de unidades entregadas. Debe ser mayor que cero.
</ParamField>

<ParamField body="observations" type="string">
  Observaciones del detalle. Máximo 250 caracteres.
</ParamField>

<ParamField body="requestDetailId" type="integer">
  Identificador del detalle de la solicitud de compra contra el cual se entrega el producto.

  - Solo puede especificarse si la entrega de compra tiene una solicitud de compra (`requestId`) asociada.
  - Debe pertenecer a la solicitud de compra asociada a la entrega.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request PATCH \
  --url "https://api.primenetcloud.com/v1/purchase-deliveries/318/details/1" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID" \
  --header "Content-Type: application/merge-patch+json" \
  --data '{
    "quantity": 45,
    "observations": "Entrega ajustada tras conteo físico"
  }'
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/purchase-deliveries/318/details/1", {
  method: "PATCH",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
    "Content-Type": "application/merge-patch+json",
  },
  body: JSON.stringify({
    quantity: 45,
    observations: "Entrega ajustada tras conteo físico"
  }),
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.patch(
    "https://api.primenetcloud.com/v1/purchase-deliveries/318/details/1",
    json={
        "quantity": 45,
        "observations": "Entrega ajustada tras conteo físico"
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
        "Content-Type": "application/merge-patch+json"
    },
)

print(response.json())
```

</CodeGroup>

### Response

Si la actualización es exitosa, el endpoint retorna `204 No Content` sin body.

### Errores

<ResponseField name="400 Bad Request">
  La entrega de compra ya ha sido cancelada y no puede actualizarse, o alguno de los identificadores especificados (`productId`, `requestDetailId`) no es válido.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ninguna entrega de compra con el `id` especificado, o el `detailId` no pertenece a la entrega.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PurchaseDeliveries.Write` requerido.
</ResponseField>

<ResponseField name="415 Unsupported Media Type">
  La solicitud no incluye el header `Content-Type` como `application/merge-patch+json`.
</ResponseField>
