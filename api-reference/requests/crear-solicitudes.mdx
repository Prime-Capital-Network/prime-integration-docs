---
title: "Crear"
api: "POST /requests"
---

Crea una nueva solicitud (request) en la empresa, a partir de una plantilla previamente configurada.

<Note>
  Este endpoint requiere el scope **`Requests.Write`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Body parameters

<ParamField body="templateId" type="integer" required>
  Identificador de la plantilla de solicitud a utilizar. Determina el menú de origen y de destino de la solicitud.
</ParamField>

<ParamField body="originOperationId" type="integer">
  Identificador de la operación de origen (ej. el `id` de la factura por pagar). Debe existir en el menú de origen de la plantilla. Es equivalente a enviar `originOperationIds` con un único elemento.

  Se debe enviar `originOperationId` **o** `originOperationIds`, pero no ambos.
</ParamField>

<ParamField body="originOperationIds" type="integer[]">
  Lista de identificadores de operaciones de origen, para solicitudes con múltiples orígenes. Actualmente solo el menú de estimados de costos (`CostEstimates`) soporta más de un origen.

  Todos los estimados deben existir, estar activas, no estar ya facturadas, no tener otra solicitud activa asociada, y compartir el mismo proveedor y la misma moneda. No se permiten IDs repetidos.
</ParamField>

<ParamField body="subject" type="string" required>
  Asunto de la solicitud. Máximo 100 caracteres.
</ParamField>

<ParamField body="description" type="string">
  Descripción de la solicitud. Máximo 250 caracteres.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request POST \
  --url "https://api.primenetcloud.com/v1/requests" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID" \
  --header "Content-Type: application/json" \
  --data '{
    "templateId": 4,
    "originOperationId": 8410,
    "subject": "Reembolso de factura DGV-002145",
    "description": "Solicitud de vale de caja chica por gastos de combustible"
  }'
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/requests", {
  method: "POST",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    templateId: 4,
    originOperationId: 8410,
    subject: "Reembolso de factura DGV-002145",
    description: "Solicitud de vale de caja chica por gastos de combustible",
  }),
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.post(
    "https://api.primenetcloud.com/v1/requests",
    json={
        "templateId": 4,
        "originOperationId": 8410,
        "subject": "Reembolso de factura DGV-002145",
        "description": "Solicitud de vale de caja chica por gastos de combustible",
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Response fields

<ResponseField name="id" type="integer">
  Identificador único de la solicitud creada.
</ResponseField>

### Ejemplo con múltiples orígenes

Solo el menú de cotizaciones de costos (`CostEstimates`) permite más de un origen. La solicitud resultante se resuelve como un único pago al proveedor, por lo que todas las cotizaciones enviadas deben compartir el mismo proveedor y la misma moneda.

```json
{
  "templateId": 4,
  "originOperationIds": [8410, 8411],
  "subject": "Pago combinado de cotizaciones",
  "description": "Pago de cotizaciones de flete y almacenaje del mismo proveedor"
}
```

### Errores

<ResponseField name="400 Bad Request">
  El `templateId` no es válido, alguna operación de origen no existe en el menú de origen de la plantilla, el menú de origen no soporta múltiples orígenes, las cotizaciones de costo enviadas no comparten proveedor o moneda, alguna cotización ya está facturada o ya tiene una solicitud activa asociada, o la combinación de menú de origen/destino de la plantilla no está permitida.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `Requests.Write` requerido.
</ResponseField>
