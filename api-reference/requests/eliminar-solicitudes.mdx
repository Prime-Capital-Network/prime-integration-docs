---
title: "Eliminar"
api: "DELETE /requests/{id}"
---

Elimina (de forma lógica) una solicitud específica.

<Note>
  Este endpoint requiere el scope **`Requests.Write`**.
</Note>

Solo se pueden eliminar solicitudes con estatus `InProgress` (En Proceso). La solicitud queda marcada con estatus `Deleted`.

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la solicitud que se desea eliminar.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request DELETE \
  --url "https://api.primenetcloud.com/v1/requests/152" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/requests/152", {
  method: "DELETE",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
  },
});

console.log(response.status); // 204
```

```python Python
import requests

response = requests.delete(
    "https://api.primenetcloud.com/v1/requests/152",
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.status_code)
```

</CodeGroup>

### Response

Si la eliminación es exitosa, el endpoint retorna `204 No Content` sin body.

### Errores

<ResponseField name="400 Bad Request">
  La solicitud no está en estatus `InProgress`.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `Requests.Write` requerido.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ninguna solicitud con el `id` especificado.
</ResponseField>
