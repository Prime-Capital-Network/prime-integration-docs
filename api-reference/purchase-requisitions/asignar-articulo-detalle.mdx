---
title: "Asignar Ítem"
api: "PUT /purchase-requisitions/{id}/details/{detailId}/item"
---

Vincula una línea de la requisición a un ítem del catálogo (producto de compra o activo fijo).

Se usa principalmente para las líneas fuera de catálogo, que deben vincularse a un ítem antes de poder [generar órdenes de compra](/api-reference/purchase-requisitions/generar-orden). A diferencia de [Actualizar Detalle](/api-reference/purchase-requisitions/actualizar-detalle), puede usarse con la requisición aprobada; la descripción, unidad, empaque, cantidad y notas de la línea se conservan.

<Note>
  Este endpoint requiere el scope **`PurchaseRequisitions.Write`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la requisición de compra.
</ParamField>

<ParamField path="detailId" type="integer" required>
  Identificador único de la línea.
</ParamField>

### Body parameters

<ParamField body="itemType" type="string" required>
  Tipo de ítem. Valores aceptados:

  - `Product`
  - `FixedAsset`
</ParamField>

<ParamField body="itemId" type="integer" required>
  Identificador del producto de compra o activo fijo, según `itemType`.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request PUT \
  --url "https://api.primenetcloud.com/v1/purchase-requisitions/37/details/102/item" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID" \
  --header "Content-Type: application/json" \
  --data '{
    "itemType": "Product",
    "itemId": 437
  }'
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/purchase-requisitions/37/details/102/item", {
  method: "PUT",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    "itemType": "Product",
    "itemId": 437
  }),
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.put(
    "https://api.primenetcloud.com/v1/purchase-requisitions/37/details/102/item",
    json={
        "itemType": "Product",
        "itemId": 437
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Response

Si la asignación es exitosa, el endpoint retorna `204 No Content` sin body.

### Errores

<ResponseField name="400 Bad Request">
  La requisición no tiene estatus `New` ni `Approved`, la línea ya tiene órdenes de compra activas, o el ítem no es válido.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ninguna requisición de compra con el `id` especificado en la URL, o el `detailId` no pertenece a esa requisición.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PurchaseRequisitions.Write` requerido.
</ResponseField>
