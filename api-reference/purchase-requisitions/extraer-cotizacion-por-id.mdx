---
title: "Obtener Cotización"
api: "GET /purchase-requisitions/{id}/quotes/{quoteId}"
---

Obtén los datos de una cotización específica de una requisición de compra.

<Note>
  Este endpoint requiere el scope **`PurchaseRequisitions.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la requisición de compra.
</ParamField>

<ParamField path="quoteId" type="integer" required>
  Identificador único de la cotización.
</ParamField>

### Query parameters

<ParamField query="include" type="string[]">
  Secciones adicionales a incluir en la respuesta. Valores aceptados:

  - `Details`
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/purchase-requisitions/37/quotes/21?include=Details" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/purchase-requisitions/37/quotes/21?include=Details", {
  method: "GET",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
  },
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/purchase-requisitions/37/quotes/21?include=Details",
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Response fields

<ResponseField name="id" type="integer">
  Identificador único de la cotización.
</ResponseField>

<ResponseField name="requisition" type="object">
  Requisición a la que pertenece la cotización.

  <Expandable title="Ver propiedades">
    <ResponseField name="id" type="integer">
      Identificador de la requisición.
    </ResponseField>

    <ResponseField name="number" type="integer">
      Número de la requisición.
    </ResponseField>

    <ResponseField name="reference" type="string">
      Referencia de la requisición.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="vendor" type="object">
  Proveedor de la cotización.

  <Expandable title="Ver propiedades">
    <ResponseField name="id" type="integer">
      Identificador del proveedor.
    </ResponseField>

    <ResponseField name="name" type="string">
      Nombre del proveedor.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="number" type="string">
  Número de la cotización asignado por el proveedor.
</ResponseField>

<ResponseField name="date" type="date">
  Fecha de la cotización.
</ResponseField>

<ResponseField name="validUntil" type="date">
  Fecha hasta la que es válida la cotización.
</ResponseField>

<ResponseField name="currency" type="object">
  Moneda de la cotización.

  <Expandable title="Ver propiedades">
    <ResponseField name="id" type="string">
      Identificador de la moneda (ej. `DOP`, `USD`).
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="paymentTerm" type="object">
  Término de pago ofrecido. Sus propiedades son `null` si no se especificó.

  <Expandable title="Ver propiedades">
    <ResponseField name="id" type="integer">
      Identificador del término de pago.
    </ResponseField>

    <ResponseField name="name" type="string">
      Nombre del término de pago.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="deliveryDays" type="integer">
  Días de entrega ofrecidos.
</ResponseField>

<ResponseField name="notes" type="string">
  Notas de la cotización.
</ResponseField>

<ResponseField name="status" type="object">
  Estatus de la cotización.

  <Expandable title="Ver propiedades">
    <ResponseField name="id" type="string">
      Identificador del estatus. Valores posibles:

      - `Active`: cotización vigente.
      - `InApproval`: tiene líneas en aprobación.
      - `Approved`: tiene líneas aprobadas y ninguna en aprobación.
      - `Cancelled`: cancelada.

      Solo `Active` y `Cancelled` se almacenan; `InApproval` y `Approved` se derivan del estado de aprobación de sus líneas.
    </ResponseField>

    <ResponseField name="name" type="string">
      Nombre traducido del estatus.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="summary" type="object">
  Resumen de las líneas de la cotización.

  <Expandable title="Ver propiedades">
    <ResponseField name="lineCount" type="integer">
      Cantidad de líneas cotizadas.
    </ResponseField>

    <ResponseField name="approvedLines" type="integer">
      Líneas aprobadas.
    </ResponseField>

    <ResponseField name="inApprovalLines" type="integer">
      Líneas en aprobación.
    </ResponseField>

    <ResponseField name="rejectedLines" type="integer">
      Líneas rechazadas.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="subTotalAmount" type="decimal">
  Subtotal de la cotización (antes de descuentos e impuestos).
</ResponseField>

<ResponseField name="discountAmount" type="decimal">
  Monto total de descuentos.
</ResponseField>

<ResponseField name="taxAmount" type="decimal">
  Monto total de impuestos.
</ResponseField>

<ResponseField name="totalAmount" type="decimal">
  Monto total de la cotización.
</ResponseField>

<ResponseField name="insertedBy" type="string">
  Usuario que creó la cotización.
</ResponseField>

<ResponseField name="insertedDate" type="string">
  Fecha y hora de creación.
</ResponseField>

<ResponseField name="updatedBy" type="string">
  Último usuario que modificó la cotización.
</ResponseField>

<ResponseField name="updatedDate" type="string">
  Fecha y hora de la última modificación.
</ResponseField>

<ResponseField name="cancelledBy" type="string">
  Usuario que canceló la cotización. `null` si no ha sido cancelada.
</ResponseField>

<ResponseField name="cancelledDate" type="string">
  Fecha y hora de la cancelación. `null` si no ha sido cancelada.
</ResponseField>

<ResponseField name="cancelledReason" type="string">
  Razón de la cancelación. `null` si no ha sido cancelada.
</ResponseField>

### Errores

<ResponseField name="404 Not Found">
  No existe ninguna requisición de compra con el `id` especificado, o el `quoteId` no pertenece a esa requisición.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PurchaseRequisitions.Read` requerido.
</ResponseField>
