---
title: "Crear Detalle"
api: "POST /purchase-requisitions/{id}/details"
---

Agrega una línea a una requisición de compra.

Las líneas solo pueden agregarse, modificarse o eliminarse mientras la requisición tiene estatus `New`, ya que son lo que se aprueba.

<Note>
  Este endpoint requiere el scope **`PurchaseRequisitions.Write`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la requisición de compra a la que se agregará la línea.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request POST \
  --url "https://api.primenetcloud.com/v1/purchase-requisitions/37/details" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID" \
  --header "Content-Type: application/json" \
  --data '{
    "itemType": "Product",
    "description": "Filtro de aire para camión Volvo FH",
    "unit": "Unidad",
    "quantity": 6
  }'
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/purchase-requisitions/37/details", {
  method: "POST",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    "itemType": "Product",
    "description": "Filtro de aire para camión Volvo FH",
    "unit": "Unidad",
    "quantity": 6
  }),
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.post(
    "https://api.primenetcloud.com/v1/purchase-requisitions/37/details",
    json={
        "itemType": "Product",
        "description": "Filtro de aire para camión Volvo FH",
        "unit": "Unidad",
        "quantity": 6
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

### Response fields

<ResponseField name="id" type="integer">
  Identificador único de la línea creada.
</ResponseField>

### Errores

<ResponseField name="400 Bad Request">
  La requisición no tiene estatus `New`; el ítem o el empaque no es válido; se especificó `description`/`unit` junto con `itemId`, o se omitieron sin `itemId`; o se especificó un empaque para un ítem que no es producto.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ninguna requisición de compra con el `id` especificado en la URL.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PurchaseRequisitions.Write` requerido.
</ResponseField>
