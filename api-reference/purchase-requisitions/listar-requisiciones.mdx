---
title: "Listar"
api: "GET /purchase-requisitions"
---

Obtén una lista paginada de requisiciones de compra en la empresa.

<Note>
  Este endpoint requiere el scope **`PurchaseRequisitions.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Query parameters

<ParamField query="start" type="date">
  Fecha de inicio del rango de búsqueda (fecha de la requisición), en formato `YYYY-MM-DD`.
</ParamField>

<ParamField query="end" type="date">
  Fecha de fin del rango de búsqueda (fecha de la requisición), en formato `YYYY-MM-DD`.
</ParamField>

<ParamField query="status" type="string">
  Filtra por el estatus de la requisición. Valores aceptados:

  - `Cancelled`
  - `New`
  - `InApproval`
  - `Approved`
  - `Quoting`
  - `Ordering`
  - `Concluded`
</ParamField>

<ParamField query="Requester.Id" type="string">
  Filtra por el identificador del usuario solicitante.
</ParamField>

<ParamField query="sort_by" type="string">
  Campo por el cual ordenar los resultados. Por defecto, por número de forma descendente (las más recientes primero). Valores aceptados:

  - `Number`
  - `Date`
  - `DateDesc`
  - `RequiredDate`
  - `RequiredDateDesc`
  - `RequesterName`
  - `DepartmentName`
  - `AssignedToName`
  - `Status`
</ParamField>

<ParamField query="skip" type="integer" default="0">
  Número de registros a omitir desde el inicio de los resultados. Utilizado junto con `take` para paginar los resultados.
</ParamField>

<ParamField query="take" type="integer" default="20">
  Número de registros a retornar. Por defecto `20`, máximo `100`.
</ParamField>

### Example request

<CodeGroup>

```bash curl

  --url "https://api.primenetcloud.com/v1/purchase-requisitions?start=2026-10-01&end=2026-10-31&status=Approved&skip=0&take=20" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

### Errores

<ResponseField name="400 Bad Request">
  Algún parámetro de búsqueda no es válido (ej. `take` mayor que `100` o un valor de `status`/`sort_by` no aceptado).
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PurchaseRequisitions.Read` requerido.
</ResponseField>
