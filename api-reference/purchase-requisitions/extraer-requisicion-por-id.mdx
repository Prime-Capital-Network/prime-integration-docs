---
title: "Obtener por ID"
api: "GET /purchase-requisitions/{id}"
---

Obtén los datos de una requisición de compra específica.

<Note>
  Este endpoint requiere el scope **`PurchaseRequisitions.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la requisición de compra.
</ParamField>

### Query parameters

<ParamField query="include" type="string[]">
  Secciones adicionales a incluir en la respuesta. Valores aceptados:

  - `Details`
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/purchase-requisitions/37?include=Details" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/purchase-requisitions/37?include=Details", {
  method: "GET",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
  },
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/purchase-requisitions/37?include=Details",
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

  </Expandable>

    <ResponseField name="name" type="string">

    </ResponseField>
  </Expandable>
</ResponseField>

      Identificador de la dimensión.

    <ResponseField name="name" type="string">
      Nombre de la dimensión.
    </ResponseField>
  </Expandable>
</ResponseField>

  Proyecto al que se carga la requisición. Sus propiedades son `null` si no se especificó.

  <Expandable title="Ver propiedades">
    <ResponseField name="id" type="integer">
      Identificador de la dimensión.
    </ResponseField>

    <ResponseField name="name" type="string">
      Nombre de la dimensión.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="storeroom" type="object">
  Almacén de inventario al que se destinan los ítems. Sus propiedades son `null` si no se especificó.

  <Expandable title="Ver propiedades">
    <ResponseField name="id" type="integer">
      Identificador del almacén.
    </ResponseField>

    <ResponseField name="code" type="string">
      Código del almacén.

    <ResponseField name="name" type="string">
      Nombre del almacén.

  </Expandable>
</ResponseField>

<ResponseField name="assignedTo" type="object">
  Usuario (comprador) asignado a gestionar la requisición. Sus propiedades son `null` si no hay ninguno.

  <Expandable title="Ver propiedades">
    <ResponseField name="id" type="string">
      Identificador del usuario.
    </ResponseField>

    <ResponseField name="name" type="string">
      Nombre completo del usuario.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="assignedDate" type="string">
  Fecha y hora en que se asignó el usuario de `assignedTo`.
</ResponseField>

<ResponseField name="status" type="object">
  Estatus de la requisición.

  <Expandable title="Ver propiedades">
    <ResponseField name="id" type="string">
      Identificador del estatus. Valores posibles:

      - `New`: recién creada; sus líneas pueden modificarse y puede enviarse a aprobación.
      - `InApproval`: enviada a aprobación mediante una [solicitud](/api-reference/requests/crear-solicitudes).
      - `Approved`: aprobada; puede cotizarse.
      - `Quoting`: aprobada y con al menos una cotización activa.
      - `Ordering`: aprobada, con unidades ya ordenadas pero aún con unidades pendientes de ordenar.
      - `Concluded`: todas las unidades de todas sus líneas han sido ordenadas.
      - `Cancelled`: cancelada.

      `Quoting`, `Ordering` y `Concluded` se derivan del avance de la requisición; para las reglas de edición la requisición sigue considerándose `Approved`.
    </ResponseField>

    <ResponseField name="name" type="string">
      Nombre traducido del estatus.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="progress" type="object">
  Resumen del avance de la requisición.

  <Expandable title="Ver propiedades">
    <ResponseField name="lineCount" type="integer">
      Cantidad de líneas.
    </ResponseField>

    <ResponseField name="quoteCount" type="integer">
      Cantidad de cotizaciones activas de la requisición.
    </ResponseField>

    <ResponseField name="quotedLines" type="integer">
      Líneas incluidas en al menos una cotización activa.
    </ResponseField>

    <ResponseField name="approvedLines" type="integer">
      Líneas con una línea de cotización aprobada (adjudicada).
    </ResponseField>

    <ResponseField name="inApprovalLines" type="integer">
      Líneas con una línea de cotización en aprobación.
    </ResponseField>

    <ResponseField name="orderedLines" type="integer">
      Líneas con al menos una unidad incluida en órdenes de compra activas.
    </ResponseField>

    <ResponseField name="pendingLines" type="integer">
      Líneas con unidades solicitadas pendientes de ordenar.
    </ResponseField>

    <ResponseField name="orderCount" type="integer">
      Cantidad de órdenes de compra activas generadas desde la requisición.
    </ResponseField>
  </Expandable>
</ResponseField>

        <ResponseField name="name" type="string">

        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="authResponse" type="object">
      Respuesta de autorización de la solicitud.

      <Expandable title="Ver propiedades">
        <ResponseField name="id" type="string">
          Identificador de la respuesta.

          - `Unassigned`
          - `Approved`
          - `Rejected`
        </ResponseField>

        <ResponseField name="name" type="string">
          Nombre traducido de la respuesta.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="respondedBy" type="string">
      Nombre del usuario que respondió la autorización.
    </ResponseField>

    <ResponseField name="responseDate" type="string">
      Fecha y hora de la respuesta.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="cancelledBy" type="string">

</ResponseField>

<ResponseField name="cancelledDate" type="string">

</ResponseField>

<ResponseField name="cancelledReason" type="string">

</ResponseField>

### Errores

<ResponseField name="404 Not Found">
  No existe ninguna requisición de compra con el `id` especificado en la URL.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PurchaseRequisitions.Read` requerido.
</ResponseField>
