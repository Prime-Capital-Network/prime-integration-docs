---
title: "Actualizar Detalle"
api: "PUT /purchase-requisitions/{id}/details/{detailId}"
---

Actualiza una línea de una requisición de compra.

Las líneas solo pueden agregarse, modificarse o eliminarse mientras la requisición tiene estatus `New`, ya que son lo que se aprueba.

<Note>
  Este endpoint requiere el scope **`PurchaseRequisitions.Write`**.
</Note>

<Warning>
  Este es un reemplazo completo del recurso (PUT). Todos los campos enviados en el body sobrescribirán el estado actual de la línea. Para cambios parciales, verificar la sección [Actualizar Parcial Detalle](/api-reference/purchase-requisitions/actualizar-parcial-detalle).
</Warning>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la requisición de compra.
</ParamField>

<ParamField path="detailId" type="integer" required>
  Identificador único de la línea a actualizar.
</ParamField>

### Body parameters

<ParamField body="itemType" type="string" required>
  Tipo de ítem de la línea. Valores aceptados:

  - `Product`: producto de compra. Ver [Productos de Compra](/api-reference/purchase-products/listar-productos-compra).
  - `FixedAsset`: activo fijo.
</ParamField>

<ParamField body="itemId" type="integer">
  Identificador del producto de compra o activo fijo, según `itemType`.

  - Si se omite, la línea queda **fuera de catálogo** y se describe con `description` y `unit`.
  - Si se especifica, `description` y `unit` deben omitirse.
</ParamField>

<ParamField body="description" type="string">
  Descripción del ítem para líneas fuera de catálogo. Máximo 250 caracteres.

  - Requerido cuando `itemId` no se especifica.
</ParamField>

<ParamField body="unit" type="string">
  Unidad de medida libre para líneas fuera de catálogo (ej. `Unidad`, `Galón`). Máximo 20 caracteres.

  - Requerido cuando `itemId` no se especifica.
</ParamField>

<ParamField body="productPackagingId" type="integer">
  Identificador del empaque del producto.

  - Solo aplica cuando `itemType` es `Product`.
</ParamField>

<ParamField body="packagingQuantity" type="decimal" >
  Unidades por empaque. Debe ser mayor que cero.
</ParamField>

<ParamField body="quantity" type="decimal" required>
  Cantidad solicitada (en empaques). Debe ser mayor que cero.
</ParamField>

<ParamField body="notes" type="string">
  Notas de la línea. Máximo 4000 caracteres.
</ParamField>

### Response

Si la actualización es exitosa, el endpoint retorna `204 No Content` sin body.

### Errores

<ResponseField name="400 Bad Request">
  La requisición no tiene estatus `New`; el ítem o el empaque no es válido; se especificó `description`/`unit` junto con `itemId`, o se omitieron sin `itemId`; o se especificó un empaque para un ítem que no es producto.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ninguna requisición de compra con el `id` especificado en la URL, o el `detailId` no pertenece a esa requisición.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PurchaseRequisitions.Write` requerido.
</ResponseField>
