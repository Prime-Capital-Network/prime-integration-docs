---
title: "Cargar Líneas"
api: "POST /purchase-requisitions/{id}/quotes/{quoteId}/load-details"
---

Agrega a la cotización todas las líneas de la requisición que aún no tiene, con la cantidad, el empaque y las unidades por empaque solicitados en la requisición, precio y descuento `0`, y el porcentaje de impuesto del producto (o `0` si no aplica). Luego se completan los precios con [Actualizar Línea](/api-reference/purchase-requisitions/actualizar-detalle-cotizacion).

La requisición debe estar aprobada (estatus `Approved`, `Quoting`, `Ordering` o `Concluded`) y la cotización no puede estar cancelada.

<Note>
  Este endpoint requiere el scope **`PurchaseRequisitions.Write`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la requisición de compra.
</ParamField>

<ParamField path="quoteId" type="integer" required>
  Identificador único de la cotización.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request POST \
  --url "https://api.primenetcloud.com/v1/purchase-requisitions/37/quotes/22/load-details" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```


### Example response

```json
{
  "count": 1

```

### Response fields

<ResponseField name="count" type="integer">
  Cantidad de líneas agregadas a la cotización.
</ResponseField>

### Errores

<ResponseField name="400 Bad Request">
  La requisición no está aprobada o la cotización está cancelada.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ninguna requisición de compra con el `id` especificado, o el `quoteId` no pertenece a esa requisición.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PurchaseRequisitions.Write` requerido.
</ResponseField>
