---
title: "Órdenes de Compra"
api: "GET /purchase-requisitions/{id}/purchase-orders"
---

Obtén una lista paginada de las órdenes de compra generadas desde una requisición.

<Note>
  Este endpoint requiere el scope **`PurchaseRequisitions.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la requisición de compra.
</ParamField>

### Query parameters

<ParamField query="skip" type="integer" default="0">
  Número de registros a omitir desde el inicio de los resultados. Utilizado junto con `take` para paginar los resultados.
</ParamField>

<ParamField query="take" type="integer" default="20">
  Número de registros a retornar. Por defecto `20`, máximo `100`.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/purchase-requisitions/37/purchase-orders?skip=0&take=20" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript

  headers: {
```

### Response fields

<ResponseField name="totalCount" type="integer">
  Total de registros.
</ResponseField>

<ResponseField name="data" type="array">
  Lista de órdenes de compra.

  <Expandable title="PurchaseOrder">
    <ResponseField name="id" type="integer">
      Identificador de la orden de compra. Ver [Órdenes de Compra](/api-reference/purchase-orders/extraer-orden-por-id).
    </ResponseField>

    <ResponseField name="number" type="integer">
      Número de comprobante de la orden de compra.
    </ResponseField>

    <ResponseField name="date" type="date">
      Fecha de la orden de compra.
    </ResponseField>

    <ResponseField name="vendor" type="object">
      Proveedor.

      <Expandable title="Ver propiedades">
        <ResponseField name="id" type="integer">
          Identificador del proveedor.
        </ResponseField>

        <ResponseField name="name" type="string">
          Nombre del proveedor.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="quoteNumbers" type="string[]">
      Números de las cotizaciones de las que provienen las líneas de la orden.
    </ResponseField>

    <ResponseField name="lineCount" type="integer">
      Cantidad de líneas de la orden.
    </ResponseField>

    <ResponseField name="currency" type="object">
      Moneda de la orden.

      <Expandable title="Ver propiedades">
        <ResponseField name="id" type="string">
          Identificador de la moneda (ej. `DOP`, `USD`).
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="totalAmount" type="decimal">
      Monto total de la orden.
    </ResponseField>

    <ResponseField name="receivedPercent" type="decimal">
      Porcentaje recibido de la orden mediante recepciones de compra.
    </ResponseField>

    <ResponseField name="insertedBy" type="string">
      Usuario que creó la orden.
    </ResponseField>

    <ResponseField name="status" type="object">
      Estatus de la orden de compra.

      <Expandable title="Ver propiedades">
        <ResponseField name="id" type="string">
          Identificador del estatus.

          Valores posibles:
          - `New`
          - `Cancelled`
          - `Deleted`
        </ResponseField>

        <ResponseField name="name" type="string">
          Nombre traducido del estatus.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

### Errores

<ResponseField name="404 Not Found">
  No existe ninguna requisición de compra con el `id` especificado en la URL.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PurchaseRequisitions.Read` requerido.
</ResponseField>
