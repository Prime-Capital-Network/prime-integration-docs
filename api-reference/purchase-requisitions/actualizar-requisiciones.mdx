---
title: "Actualizar"
api: "PUT /purchase-requisitions/{id}"
---

Actualiza los datos generales de una requisición de compra. Las líneas se gestionan con los endpoints de detalles.

<Note>
  Este endpoint requiere el scope **`PurchaseRequisitions.Write`**.
</Note>

<Warning>
  Este es un reemplazo completo del recurso (PUT). Todos los campos enviados en el body sobrescribirán el estado actual de la requisición. Para cambios parciales, verificar la sección [Actualizar Parcial](/api-reference/purchase-requisitions/actualizar-parcial-requisiciones).
</Warning>

Solo pueden actualizarse requisiciones con estatus `New` o `Approved` (incluyendo `Quoting`, `Ordering` y `Concluded`). En una requisición aprobada no pueden cambiarse el solicitante (`requesterId`) ni las dimensiones (`departmentId`, `costCenterId`, `projectId`), ya que son parte de lo aprobado.

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la requisición de compra a actualizar.
</ParamField>

### Body parameters

<ParamField body="requesterId" type="string" required>
  Identificador del usuario solicitante.
</ParamField>

<ParamField body="requiredDate" type="date">
  Fecha en que se requieren los ítems, en formato `YYYY-MM-DD`.

  - No puede ser una fecha pasada (solo se valida si cambia).
</ParamField>

<ParamField body="reference" type="string">
  Referencia de la requisición. Máximo 200 caracteres.
</ParamField>

<ParamField body="departmentId" type="integer">
  Identificador del departamento (Dimensión).

  - Debe ser una dimensión con el campo `typeId` igual a `1` (Department).
</ParamField>

<ParamField body="costCenterId" type="integer">
  Identificador del centro de costo (Dimensión).

  - Debe ser una dimensión con el campo `typeId` igual a `2` (Cost Center).
</ParamField>

<ParamField body="projectId" type="integer">
  Identificador del proyecto (Dimensión).

  - Debe ser una dimensión con el campo `typeId` igual a `3` (Project).
</ParamField>

<ParamField body="storeroomId" type="integer">
  Identificador del almacén de inventario (Storeroom) al que se destinan los ítems. Ver [Almacenes de Inventario](/api-reference/storerooms/listar-almacenes).
</ParamField>

<ParamField body="assignedToId" type="string">
  Identificador del usuario (comprador) asignado a gestionar la requisición.
</ParamField>

### Response

Si la actualización es exitosa, el endpoint retorna `204 No Content` sin body.

### Errores

<ResponseField name="400 Bad Request">
  La requisición no tiene estatus `New` ni `Approved`; se intentó cambiar el solicitante o las dimensiones de una requisición aprobada; algún identificador no es válido o una dimensión no es del tipo esperado; o `requiredDate` se cambió a una fecha pasada.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ninguna requisición de compra con el `id` especificado en la URL.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PurchaseRequisitions.Write` requerido.
</ResponseField>
