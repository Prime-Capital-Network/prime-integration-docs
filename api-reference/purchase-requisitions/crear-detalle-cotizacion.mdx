---
title: "Crear Línea"
api: "POST /purchase-requisitions/{id}/quotes/{quoteId}/details"
---

Agrega una línea a una cotización.

La requisición debe estar aprobada (estatus `Approved`, `Quoting`, `Ordering` o `Concluded`) y la cotización no puede estar cancelada.

<Note>
  Este endpoint requiere el scope **`PurchaseRequisitions.Write`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la requisición de compra.
</ParamField>

<ParamField path="quoteId" type="integer" required>
  Identificador único de la cotización.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request POST \
  --url "https://api.primenetcloud.com/v1/purchase-requisitions/37/quotes/22/details" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID" \
  --header "Content-Type: application/json" \
  --data '{
    "requisitionDetailId": 101,
    "quantity": 4,
    "price": 320,
    "taxPercent": 18
  }'
```


```python Python
import requests

response = requests.post(
    "https://api.primenetcloud.com/v1/purchase-requisitions/37/quotes/22/details",
    json={
        "requisitionDetailId": 101,
        "quantity": 4,
        "price": 320,
        "taxPercent": 18
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

### Errores

<ResponseField name="400 Bad Request">
  La requisición no está aprobada o la cotización está cancelada; el descuento es mayor que el precio; o se especificó un empaque no válido o para una línea que no es un producto. También si la línea de la requisición no pertenece a la requisición de la cotización o ya está en la cotización.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ninguna requisición de compra con el `id` especificado, o el `quoteId` no pertenece a esa requisición.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PurchaseRequisitions.Write` requerido.
</ResponseField>
