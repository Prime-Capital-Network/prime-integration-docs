---
title: "Cancelar"
api: "POST /purchase-requisitions/{id}/cancel"
---

Cancela una requisición de compra.

Si la requisición está en aprobación (`InApproval`) y su solicitud de aprobación sigue en curso, la solicitud se elimina al cancelarla.

<Note>
  Este endpoint requiere el scope **`PurchaseRequisitions.Write`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la requisición de compra a cancelar.
</ParamField>

### Body parameters

<ParamField body="reason" type="string">
  Razón de la cancelación. Máximo 250 caracteres.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request POST \
  --url "https://api.primenetcloud.com/v1/purchase-requisitions/37/cancel" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID" \
  --header "Content-Type: application/json" \
  --data '{
    "reason": "El mantenimiento fue reprogramado para el próximo trimestre"
  }'
```


```python Python

```

</CodeGroup>

### Response

Si la cancelación es exitosa, el endpoint retorna `204 No Content` sin body.

### Errores

<ResponseField name="400 Bad Request">
  La requisición ya ha sido cancelada, tiene órdenes de compra activas, o tiene líneas de cotización en aprobación.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ninguna requisición de compra con el `id` especificado en la URL.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `PurchaseRequisitions.Write` requerido.
</ResponseField>
