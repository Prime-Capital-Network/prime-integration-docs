Busca incoterms por nombre o identificador, opcionalmente filtrando por el medio de transporte al cual aplican.

<Note>
  Este endpoint requiere el scope **`Incoterms.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Query parameters

<ParamField query="value" type="string">
  Texto libre para buscar por nombre o identificador del incoterm.
</ParamField>

<ParamField query="filter_by" type="string">
  Filtra los incoterms aplicables a un medio de transporte específico. Valores aceptados:

  - `Air`
  - `Sea`
  - `Ground`
  - `Rail`
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/incoterms/search?value=FOB&filter_by=Sea" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch(
  "https://api.primenetcloud.com/v1/incoterms/search?value=FOB&filter_by=Sea",
  {
    method: "GET",
    headers: {
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID",
    },
  }
);

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/incoterms/search",
    params={
        "value": "FOB",
        "filter_by": "Sea",
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Example response

```json
[
  {
    "id": "FOB",
    "name": "Free On Board"
  }
]
```

### Response fields

<ResponseField name="id" type="string">
  Identificador único del incoterm.
</ResponseField>

<ResponseField name="name" type="string">
  Nombre del incoterm.
</ResponseField>

### Errores

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `Incoterms.Read` requerido.
</ResponseField>
