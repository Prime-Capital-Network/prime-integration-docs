---
title: "Obtener Transporte Por ID"
sidebarTitle: "Obtener por ID"
description: "Permite extraer un registro de transporte terrestre en específico mediante REST API"
api: "GET /ground-transportations/{id}"
---

Obtén un registro de transporte terrestre por ID en la empresa.

<Note>
  Este endpoint requiere el scope **`GroundTransportations.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único del transporte terrestre.
</ParamField>

### Query parameters

<ParamField query="include" type="string">
  Permite incluir relaciones adicionales en la respuesta. Valor aceptado:

  - `Dispatches` — incluye el arreglo `dispatches` con los despachos del transporte.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/ground-transportations/5321?include=Dispatches" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch(
  "https://api.primenetcloud.com/v1/ground-transportations/5321?include=Dispatches",
  {
    method: "GET",
    headers: {
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID"
    },
  }
);
const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/ground-transportations/5321",
    params={"include": "Dispatches"},
    headers={
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID"
    }
)
print(response.json())
```

</CodeGroup>

### Errores

<ResponseField name="404 Not Found">
  No existe ningún transporte terrestre con el `id` especificado en la URL.
</ResponseField>

<ResponseField name="403 Forbidden">

</ResponseField>
