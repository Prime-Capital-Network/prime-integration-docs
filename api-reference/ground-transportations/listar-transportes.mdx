Obtén una lista paginada de transportes terrestres en la empresa.

<Note>
  Este endpoint requiere el scope **`GroundTransportations.Read`**.
</Note>

<Warning>
  Debes filtrar por al menos uno de los siguientes query parameters: `Loading.Date`, `Unloading.Date` o `InsertedDate`.
</Warning>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Query parameters

<ParamField query="sort_by" type="string">
  Campo por el cual ordenar los resultados. Valores aceptados:

  - `Id`
  - `TransactionNumber`
  - `TrackingNumber`
  - `Customer.Id`
  - `Customer.Name`
  - `Loading.Date`
  - `Loading.Zone.Name`
  - `Unloading.Date`
  - `Unloading.Zone.Name`
  - `HouseBL`
  - `JobNumber`
  - `AssignedTo.Id`
  - `AssignedTo.FullName`
  - `Status`
  - `InsertedDate`
</ParamField>

<ParamField query="skip" default="0" type="integer">
  Número de registros a omitir desde el inicio de los resultados. Utilízado junto con `take` para paginar los resultados.
</ParamField>

<ParamField query="take" default="20" type="integer">
  Número de registros a retornar. Por defecto `20`, máximo `100`.
</ParamField>

<ParamField query="TransactionNumber" type="RangeSearchFilter<integer>">
  Filtra por número de transacción del transporte.
</ParamField>

<ParamField query="TrackingNumber" type="RangeSearchFilter<integer>">
  Filtra por número de tracking del transporte.
</ParamField>

<ParamField query="Customer.Name" type="StringSearchFilter">
  Filtra por el nombre del cliente.
</ParamField>

<ParamField query="Loading.Date" type="RangeSearchFilter<datetime>">
  Filtra por la fecha de carga.
</ParamField>

<ParamField query="Loading.Zone.Name" type="StringSearchFilter">
  Filtra por el nombre de la zona de carga.
</ParamField>

<ParamField query="Unloading.Date" type="RangeSearchFilter<datetime>">
  Filtra por la fecha de descarga.
</ParamField>

<ParamField query="Unloading.Zone.Name" type="StringSearchFilter">
  Filtra por el nombre de la zona de descarga.
</ParamField>

<ParamField query="HouseBL" type="StringSearchFilter">
  Filtra por el número de BL del house asociado.
</ParamField>

<ParamField query="JobNumber" type="StringSearchFilter">
  Filtra por el número de JOB/PO.
</ParamField>

<ParamField query="AssignedTo.Id" type="StringSearchFilter">
  Filtra por el identificador del usuario asignado.
</ParamField>

<ParamField query="AssignedTo.FullName" type="StringSearchFilter">
  Filtra por el nombre completo del usuario asignado.
</ParamField>

<ParamField query="Status.Id" type="EnumSearchFilter">
  Filtra por el estatus del transporte. Valores aceptados:

  - `Cancelled`
  - `Quoted`
  - `Unassigned`
  - `InCoordination`
  - `Completed`
  - `InProcess`
  - `Declined`
  - `Dispatched`
  - `Delivered`
</ParamField>

<ParamField query="InsertedDate" type="RangeSearchFilter<datetime>">
  Filtra por la fecha de creación del transporte.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/ground-transportations?Loading.Date_min=2026-07-01&skip=0&take=20" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch(
  "https://api.primenetcloud.com/v1/ground-transportations?Loading.Date_min=2026-07-01&skip=0&take=20",
  {
    method: "GET",
    headers: {
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID"
    },
  }
);

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/ground-transportations",
    params={
        "Loading.Date_min": "2026-07-01",
        "skip": 0,
        "take": 20,
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID"
    }
)

print(response.json())
```

</CodeGroup>
