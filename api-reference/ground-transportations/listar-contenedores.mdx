---
title: "Listar Contenedores"
sidebarTitle: "Contenedores"
description: "Permite extraer los contenedores asociados a un transporte terrestre mediante REST API"
api: "GET /ground-transportations/{id}/containers"
---

Obtén la lista completa de contenedores asociados a un transporte terrestre (a través de los chasis de sus despachos). Este endpoint no pagina resultados.

<Note>
  Este endpoint requiere el scope **`GroundTransportations.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único del transporte terrestre.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/ground-transportations/5321/containers" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch(
  "https://api.primenetcloud.com/v1/ground-transportations/5321/containers",
  {
    method: "GET",
    headers: {
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID"
    },
  }
);

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/ground-transportations/5321/containers",
    headers={
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID"
    }
)

print(response.json())
```

</CodeGroup>

### Errores

<ResponseField name="404 Not Found">
  No existe ningún transporte terrestre con el `id` especificado en la URL.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `GroundTransportations.Read` requerido.
</ResponseField>
