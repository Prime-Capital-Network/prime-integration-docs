---
title: "Crear Despacho"
description: "Este endpoint permite agregar un nuevo despacho a un transporte terrestre existente."
api: "POST /ground-transportations/{id}/dispatches"
---

<Note>
  Este endpoint requiere el scope **`GroundTransportations.Write`**.
</Note>

<Warning>
  No es posible agregar despachos a un transporte que ya haya sido cancelado.
</Warning>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único del transporte terrestre.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request POST \
  --url "https://api.primenetcloud.com/v1/ground-transportations/5321/dispatches" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID" \
  --header "Content-Type: application/json" \
  --data '{
    "vehicleId": 45,
    "status": "InCoordination"
  }'
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/ground-transportations/5321/dispatches", {
  method: "POST",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    vehicleId: 45,
    status: "InCoordination",
  }),
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.post(
    "https://api.primenetcloud.com/v1/ground-transportations/5321/dispatches",
    json={
        "vehicleId": 45,
        "status": "InCoordination",
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Response

Si la creación es exitosa, el endpoint retorna `201 Created` sin body, con el header `Location` apuntando al nuevo despacho.

### Errores

<ResponseField name="400 Bad Request">
  El transporte ya ha sido cancelado, el `vehicleId` no es válido, o `driverId`/`staffs.staffId` tienen valores repetidos.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ningún transporte terrestre con el `id` especificado en la URL.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `GroundTransportations.Write` requerido.
</ResponseField>
