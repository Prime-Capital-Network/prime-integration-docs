---
title: "Actualizar Despacho"
api: "PUT /ground-transportations/{id}/dispatches/{dispatchId}"
---

Este endpoint permite actualizar los datos de un despacho existente en un transporte terrestre.

<Note>
  Este endpoint requiere el scope **`GroundTransportations.Write`**.
</Note>

<Warning>
  Este es un reemplazo completo del recurso (PUT). Todos los campos enviados en el body sobrescribirán el estado actual del despacho. No es posible actualizar despachos de un transporte que ya haya sido cancelado.
</Warning>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único del transporte terrestre.
</ParamField>

<ParamField path="dispatchId" type="integer" required>
  Identificador único del despacho a actualizar.
</ParamField>

### Body parameters

<ParamField body="physicalNumber" type="string">
  Número físico del despacho. Máximo 10 caracteres.
</ParamField>

<ParamField body="vehicleId" type="integer" required>
  Identificador del vehículo asignado al despacho.
</ParamField>

<ParamField body="driverId" type="integer">
  Identificador del conductor asignado.

  - No puede repetirse entre `driverId` y los `staffs.staffId` del mismo despacho.
</ParamField>

<ParamField body="staffs" type="object[]">
  Personal adicional asignado al despacho. Máximo 5 elementos.
</ParamField>

<ParamField body="staffs.staffId" type="integer" required>
  Identificador del personal.

  - No puede repetirse entre sí ni con `driverId`.
</ParamField>

<ParamField body="staffs.typeId" type="integer" required>
  Identificador del tipo de personal.
</ParamField>

<ParamField body="loadingDate" type="datetime">
  Fecha de carga del despacho.
</ParamField>

<ParamField body="dispatchDate" type="datetime">
  Fecha de salida del despacho.
</ParamField>

<ParamField body="arrivalDate" type="datetime">
  Fecha de llegada del despacho.
</ParamField>

<ParamField body="receivedDate" type="datetime">
  Fecha de recepción del despacho.
</ParamField>

<ParamField body="returnedDate" type="datetime">
  Fecha de retorno del vehículo.
</ParamField>

<ParamField body="status" type="string" required>
  Estatus del despacho. Valores aceptados:

  - `Cancelled`
  - `Dispatched`
  - `Arrived`
  - `Received`
  - `IncidentReported`
  - `Started`
  - `InCoordination`
  - `Delivered`
  - `Returned`
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request PUT \
  --url "https://api.primenetcloud.com/v1/ground-transportations/5321/dispatches/901" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID" \
  --header "Content-Type: application/json" \
  --data '{
    "vehicleId": 45,
    "status": "Dispatched"
  }'
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/ground-transportations/5321/dispatches/901", {
  method: "PUT",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    vehicleId: 45,
    status: "Dispatched",
  }),
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.put(
    "https://api.primenetcloud.com/v1/ground-transportations/5321/dispatches/901",
    json={
        "vehicleId": 45,
        "status": "Dispatched",
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Response

Si la actualización es exitosa, el endpoint retorna `204 No Content` sin body.

### Errores

<ResponseField name="400 Bad Request">
  El transporte ya ha sido cancelado, el `vehicleId` no es válido, o `driverId`/`staffs.staffId` tienen valores repetidos.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ningún transporte terrestre con el `id` especificado, o ningún despacho con el `dispatchId` especificado.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `GroundTransportations.Write` requerido.
</ResponseField>
