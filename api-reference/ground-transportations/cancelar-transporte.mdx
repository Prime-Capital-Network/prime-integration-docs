Cancela un transporte terrestre en la empresa.

<Note>
  Este endpoint requiere el scope **`GroundTransportations.Write`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único del transporte terrestre a cancelar.
</ParamField>

### Body parameters

<ParamField body="reason" type="string">
  Razón de la cancelación. Máximo 250 caracteres.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request POST \
  --url "https://api.primenetcloud.com/v1/ground-transportations/5321/cancel" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID" \
  --header "Content-Type: application/json" \
  --data '{
    "reason": "Cliente canceló el pedido"
  }'
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/ground-transportations/5321/cancel", {
  method: "POST",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    reason: "Cliente canceló el pedido",
  }),
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.post(
    "https://api.primenetcloud.com/v1/ground-transportations/5321/cancel",
    json={
        "reason": "Cliente canceló el pedido",
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Response

Si la cancelación es exitosa, el endpoint retorna `204 No Content` sin body.

### Errores

<ResponseField name="400 Bad Request">
  El transporte ya ha sido cancelado, o tiene cuentas por cobrar/pagar vinculadas.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ningún transporte terrestre con el `id` especificado en la URL.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `GroundTransportations.Write` requerido.
</ResponseField>
