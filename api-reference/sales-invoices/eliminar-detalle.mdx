---
title: "Eliminar Detalle"
api: "DELETE /sales-invoices/{id}/details/{detailId}"
---

Elimina un detalle de una factura por cobrar. El sistema recalcula automáticamente los totales y las cuentas contables de la factura.

<Note>
  Este endpoint requiere el scope **`SalesInvoices.Write`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la factura a la que pertenece el detalle.
</ParamField>

<ParamField path="detailId" type="integer" required>
  Identificador único del detalle a eliminar.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request DELETE \
  --url "https://api.primenetcloud.com/v1/sales-invoices/2210/details/3301" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/sales-invoices/2210/details/3301", {
  method: "DELETE",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
  },
});

console.log(response.status);
```

```python Python
import requests

response = requests.delete(
    "https://api.primenetcloud.com/v1/sales-invoices/2210/details/3301",
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.status_code)
```

</CodeGroup>

### Response

Si la eliminación es exitosa, el endpoint retorna `204 No Content` sin body.

### Errores

<ResponseField name="400 Bad Request">
  La factura ya está posteada (campo `status` como `Posted`) o es un e-CF ya enviado a la DGII (código `ISSUED_ECF`).
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `SalesInvoices.Write` requerido.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ninguna factura con el `id` especificado (o es una proforma), o el `detailId` no pertenece a la factura.
</ResponseField>
