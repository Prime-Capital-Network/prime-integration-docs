---
title: "Actualizar Detalle"
api: "PUT /sales-invoices/{id}/details/{detailId}"
---

Actualiza todos los datos de un detalle de una factura por cobrar. Los campos que no se envíen quedan con su valor por defecto (`null`). Para modificar solo algunos campos usa [Actualizar Parcial Detalle](/api-reference/sales-invoices/actualizar-parcial-detalle).

<Note>
  Este endpoint requiere el scope **`SalesInvoices.Write`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la factura.
</ParamField>

<ParamField path="detailId" type="integer" required>
  Identificador único del detalle a actualizar.
</ParamField>

### Body parameters

<ParamField body="chargeId" type="integer" required>
  Identificador del cargo.

  - Debe ser un cargo usado para ventas (`isUsedForSales` como `true`) y con una cuenta de ingresos asignada.
</ParamField>

<ParamField body="chargeDescription" type="string">
  Descripción del cargo en la factura. Máximo 120 caracteres. Si no se envía, se usa el nombre del cargo.
</ParamField>

<ParamField body="chargeDetails" type="string">
  Detalle adicional del cargo. Máximo 250 caracteres.
</ParamField>

<ParamField body="calculationTypeId" type="string">
  Identificador del tipo de cálculo. Máximo 3 caracteres.
</ParamField>

<ParamField body="quantity" type="decimal" required>
  Cantidad. Debe ser mayor que cero.
</ParamField>

<ParamField body="price" type="decimal">
  Precio unitario. Debe ser mayor que cero.
</ParamField>

<ParamField body="taxPercent" type="decimal">
  Porcentaje de impuesto (ITBIS). Debe ser mayor o igual a cero.

  - Solo puede ser distinto de cero si el cliente de la factura está sujeto a impuesto (el porcentaje de impuesto de su tipo de negocio es distinto de cero).
</ParamField>

<ParamField body="discount" type="decimal">
  Descuento por unidad. Debe ser mayor o igual a cero. El subtotal del detalle es `quantity * (price - discount)`.
</ParamField>

<ParamField body="operationCategory" type="string">
  Categoría de la operación logística asociada. Requerido si `operationId` está presente. Valores aceptados:

  - `Shipment` (Embarque)
  - `CustomManagement` (Aduanas)
  - `Additional` (Misceláneos)
  - `InlandFreight` (Transporte Terrestre)
</ParamField>

<ParamField body="operationId" type="integer">
  Identificador de la operación logística asociada. Requerido si `operationCategory` está presente.
</ParamField>

<ParamField body="masterId" type="integer">
  Identificador del master asociado.
</ParamField>

<ParamField body="departmentId" type="integer">
  Identificador del departamento. Debe ser una dimensión de tipo departamento.
</ParamField>

<ParamField body="costCenterId" type="integer">
  Identificador del centro de costo. Debe ser una dimensión de tipo centro de costo.
</ParamField>

<ParamField body="projectId" type="integer">
  Identificador del proyecto. Debe ser una dimensión de tipo proyecto.
</ParamField>

### Response

Si la actualización es exitosa, el endpoint retorna `204 No Content` sin body.

### Errores

<ResponseField name="400 Bad Request">
  La factura ya está posteada (campo `status` como `Posted`), es un e-CF ya enviado a la DGII (código `IssuedEcf`), o la solicitud no cumple alguna de las reglas de los campos.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `SalesInvoices.Write` requerido.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ninguna factura con el `id` especificado (o es una proforma), o el `detailId` no pertenece a la factura.
</ResponseField>
