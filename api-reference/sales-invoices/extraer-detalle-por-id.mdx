---
title: "Obtener Detalle por ID"
sidebarTitle: "Obtener Detalle por ID"
api: "GET /sales-invoices/{id}/details/{detailId}"
---

Obtén un detalle específico de una factura por cobrar.

<Note>
  Este endpoint requiere el scope **`SalesInvoices.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la factura.
</ParamField>

<ParamField path="detailId" type="integer" required>
  Identificador único del detalle.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/sales-invoices/2210/details/3301" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/sales-invoices/2210/details/3301", {
  method: "GET",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
  },
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/sales-invoices/2210/details/3301",
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Response fields

<ResponseField name="id" type="integer">
  Identificador único del detalle.
</ResponseField>

<ResponseField name="charge" type="object">
  Cargo facturado.

  <Expandable title="propiedades">
    <ResponseField name="id" type="integer">
      Identificador del cargo.
    </ResponseField>

    <ResponseField name="name" type="string">
      Nombre del cargo.
    </ResponseField>

    <ResponseField name="fastCode" type="string">
      Código rápido del cargo.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="chargeDescription" type="string">
  Descripción del cargo en la factura.
</ResponseField>

<ResponseField name="chargeDetails" type="string">
  Detalle adicional del cargo.
</ResponseField>

<ResponseField name="calculationType" type="object">
  Tipo de cálculo del cargo.

  <Expandable title="propiedades">
    <ResponseField name="id" type="string">
      Identificador del tipo de cálculo.
    </ResponseField>

    <ResponseField name="name" type="string">
      Nombre del tipo de cálculo.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="quantity" type="decimal">
  Cantidad.
</ResponseField>

<ResponseField name="price" type="decimal">
  Precio unitario.
</ResponseField>

<ResponseField name="taxPercent" type="decimal">
  Porcentaje de impuesto (ITBIS) aplicado.
</ResponseField>

<ResponseField name="discount" type="decimal">
  Descuento por unidad.
</ResponseField>

<ResponseField name="operation" type="object">
  Operación logística asociada. `null` si no está asociado a ninguna operación.

  <Expandable title="propiedades">
    <ResponseField name="id" type="integer">
      Identificador de la operación.
    </ResponseField>

    <ResponseField name="category" type="string">
      Categoría de la operación: `Shipment`, `CustomManagement`, `Additional` o `InlandFreight`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="department" type="object">
  Departamento asignado al detalle.

  <Expandable title="propiedades">
    <ResponseField name="id" type="integer">
      Identificador del departamento.
    </ResponseField>

    <ResponseField name="name" type="string">
      Nombre del departamento.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="costCenter" type="object">
  Centro de costo asignado al detalle.

  <Expandable title="propiedades">
    <ResponseField name="id" type="integer">
      Identificador del centro de costo.
    </ResponseField>

    <ResponseField name="name" type="string">
      Nombre del centro de costo.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="project" type="object">
  Proyecto asignado al detalle.

  <Expandable title="propiedades">
    <ResponseField name="id" type="integer">
      Identificador del proyecto.
    </ResponseField>

    <ResponseField name="name" type="string">
      Nombre del proyecto.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="insertedBy" type="string">
  Usuario o integración (nombre del API Key) que creó el detalle.
</ResponseField>

<ResponseField name="insertedDate" type="datetime">
  Fecha y hora de creación.
</ResponseField>

<ResponseField name="updatedBy" type="string">
  Usuario o integración que actualizó por última vez el detalle.
</ResponseField>

<ResponseField name="updatedDate" type="datetime">
  Fecha y hora de la última actualización.
</ResponseField>

### Errores

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `SalesInvoices.Read` requerido.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ninguna factura con el `id` especificado (o es una proforma), o el `detailId` no pertenece a la factura.
</ResponseField>
