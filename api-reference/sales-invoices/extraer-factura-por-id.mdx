---
title: "Obtener factura por ID"
sidebarTitle: "Obtener por ID"
description: "Permite extraer una factura por cobrar en específico mediante REST API"
api: "GET /sales-invoices/{id}"
---

Obtén una factura por cobrar por ID en la empresa.

<Note>
  Este endpoint requiere el scope **`SalesInvoices.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la factura.
</ParamField>

### Query parameters

<ParamField query="include" type="string[]">
  Secciones adicionales a incluir en la respuesta. Valores aceptados:

  - `Details`
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/sales-invoices/2210?include=Details" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/sales-invoices/2210?include=Details", {
  method: "GET",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
  },
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/sales-invoices/2210",
    params={
        "include": "Details",
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Response fields

<ResponseField name="id" type="integer">
  Identificador único de la factura.
</ResponseField>

<ResponseField name="transactionNumber" type="integer">
  Número de transacción de la factura.
</ResponseField>

<ResponseField name="journalNumber" type="integer">
  Número de comprobante contable de la factura.
</ResponseField>

<ResponseField name="date" type="date">
  Fecha de la factura.
</ResponseField>

<ResponseField name="dueDate" type="datetime">
  Fecha de vencimiento, calculada a partir de la fecha y del término de pago.
</ResponseField>

<ResponseField name="proformaNumber" type="integer">
  Número de la proforma de la que proviene la factura. `null` si no proviene de una proforma.
</ResponseField>

<ResponseField name="proformaDate" type="datetime">
  Fecha de la proforma de la que proviene la factura.
</ResponseField>

<ResponseField name="isProforma" type="boolean">
  Indica si el documento es una proforma. Siempre `false` mediante API Key.
</ResponseField>

<ResponseField name="customer" type="object">
  Cliente facturado.

  <Expandable title="propiedades">
    <ResponseField name="id" type="integer">
      Identificador del cliente.
    </ResponseField>

    <ResponseField name="name" type="string">
      Nombre del cliente.

</ResponseField>

### Errores

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `SalesInvoices.Read` requerido.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ninguna factura con el `id` especificado en la URL, o es una proforma.
</ResponseField>
