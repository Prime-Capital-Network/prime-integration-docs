---
title: "Crear Detalle"
api: "POST /sales-invoices/{id}/details"
---

Agrega un detalle a una factura por cobrar. El sistema recalcula automáticamente los totales y las cuentas contables de la factura.

<Note>
  Este endpoint requiere el scope **`SalesInvoices.Write`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la factura a la que se agregará el detalle.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request POST \
  --url "https://api.primenetcloud.com/v1/sales-invoices/2210/details" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID" \
  --header "Content-Type: application/json" \
  --data '{
    "chargeId": 87,
    "chargeDescription": "Flete marítimo Miami - Santo Domingo",
    "chargeDetails": "Contenedor 40' HC",
    "quantity": 1,
    "price": 1850,
    "taxPercent": 18,
    "discount": 0,
    "operationCategory": "Shipment",
    "operationId": 5321,
    "departmentId": 3
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.primenetcloud.com/v1/sales-invoices/2210/details",
    json={
        "chargeId": 87,
        "chargeDescription": "Flete marítimo Miami - Santo Domingo",
        "chargeDetails": "Contenedor 40' HC",
        "quantity": 1,
        "price": 1850,
        "taxPercent": 18,

        "operationCategory": "Shipment",
        "operationId": 5321,
        "departmentId": 3
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",

    },

print(response.json())
```

### Response fields

  Identificador único del detalle creado.
</ResponseField>

### Errores

<ResponseField name="400 Bad Request">
  La factura ya está posteada (campo `status` como `Posted`), es un e-CF ya enviado a la DGII (código `ISSUED_ECF`), o la solicitud no cumple alguna de las reglas de los campos.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `SalesInvoices.Write` requerido.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ninguna factura con el `id` especificado en la URL, o es una proforma.
</ResponseField>
