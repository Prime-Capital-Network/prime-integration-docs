---
title: "Listar Detalles"
api: "GET /sales-invoices/{id}/details"
---

Obtén todos los detalles (líneas) de una factura por cobrar.

<Note>
  Este endpoint requiere el scope **`SalesInvoices.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la factura.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/sales-invoices/2210/details" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/sales-invoices/2210/details", {
  method: "GET",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
  },
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/sales-invoices/2210/details",
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Errores

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `SalesInvoices.Read` requerido.
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ninguna factura con el `id` especificado en la URL, o es una proforma.
</ResponseField>
