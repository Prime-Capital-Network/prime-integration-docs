---
title: "Listar"
api: "GET /sales-invoices"
---

Obtén una lista paginada de facturas por cobrar (facturas de venta) de la empresa.

<Note>
  Este endpoint requiere el scope **`SalesInvoices.Read`**.
</Note>

<Info>
  Las proformas no están disponibles mediante API Key: no aparecen en el listado y cualquier endpoint que reciba el `id` de una proforma responde `404 Not Found`. Las proformas se crean y se convierten en facturas desde PrimeERP.
</Info>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Query parameters

<ParamField query="start" type="datetime" required>
  Fecha de inicio del rango de búsqueda (fecha de la factura).
</ParamField>

<ParamField query="end" type="datetime" required>
  Fecha de fin del rango de búsqueda (fecha de la factura).
</ParamField>

<ParamField query="sort_by" type="string">
  Campo por el cual ordenar los resultados. Valores aceptados:

  - `Id`
  - `TransactionNumber`
  - `JournalNumber`
  - `Date`
  - `Customer.Id`
  - `Customer.Name`
  - `NCF`
  - `Currency.Id`
  - `PaymentTerm.Name`
  - `BilledAmount`
  - `AmountTaxed`
  - `AmountExempt`
  - `TotalAmount`
  - `TotalDebit`
  - `TotalCredit`
  - `Status`
  - `InsertedBy`
</ParamField>

<ParamField query="skip" default="0" type="integer">
  Número de registros a omitir desde el inicio de los resultados. Utilizado junto con `take` para paginar los resultados.
</ParamField>

<ParamField query="take" default="20" type="integer">
  Número de registros a retornar. Por defecto `20`, máximo `100`.
</ParamField>

<ParamField query="Criteria" type="string">
  Filtra las facturas según el estatus de su comprobante contable.

  Valores aceptados:
  - `Active`
  - `New`
  - `Posted`
  - `Cancelled`
  - `Deleted`
</ParamField>

<ParamField query="TransactionNumber" type="RangeSearchFilter<integer>">
  Filtra por el número de transacción de la factura.
</ParamField>

<ParamField query="JournalNumber" type="RangeSearchFilter<integer>">
  Filtra por el número de comprobante contable de la factura.
</ParamField>

<ParamField query="Customer.Id" type="RangeSearchFilter<integer>">
  Filtra por el identificador del cliente.
</ParamField>

<ParamField query="Customer.Name" type="StringSearchFilter">
  Filtra por el nombre del cliente.
</ParamField>

<ParamField query="NCF" type="StringSearchFilter">
  Filtra por el número de comprobante fiscal.
</ParamField>

<ParamField query="ProformaNumber" type="RangeSearchFilter<integer>">
  Filtra por el número de la proforma de la que proviene la factura.
</ParamField>

<ParamField query="ProformaDate" type="RangeSearchFilter<datetime>">
  Filtra por la fecha de la proforma de la que proviene la factura.
</ParamField>

<ParamField query="Currency.Id" type="StringSearchFilter">
  Filtra por el identificador de la moneda.
</ParamField>

<ParamField query="PaymentTerm.Name" type="StringSearchFilter">
  Filtra por el nombre del término de pago.
</ParamField>

<ParamField query="BilledAmount" type="RangeSearchFilter<decimal>">
  Filtra por el monto facturado antes de impuestos.
</ParamField>

<ParamField query="TaxAmount" type="RangeSearchFilter<decimal>">
  Filtra por el monto del impuesto.
</ParamField>

<ParamField query="AmountTaxed" type="RangeSearchFilter<decimal>">
  Filtra por el monto gravado.
</ParamField>

<ParamField query="AmountExempt" type="RangeSearchFilter<decimal>">
  Filtra por el monto exento.
</ParamField>

<ParamField query="TotalAmount" type="RangeSearchFilter<decimal>">
  Filtra por el monto total de la factura.
</ParamField>

<ParamField query="TotalToPay" type="RangeSearchFilter<decimal>">
  Filtra por el balance pendiente de cobro.
</ParamField>

<ParamField query="TotalDebit" type="RangeSearchFilter<decimal>">
  Filtra por el total del débito.
</ParamField>

<ParamField query="TotalCredit" type="RangeSearchFilter<decimal>">
  Filtra por el total del crédito.
</ParamField>

<ParamField query="PaymentStatus.Id" type="EnumSearchFilter">
  Filtra por el estatus de pago. Valores aceptados:

  - `Paid`
  - `Unpaid`
  - `Advance`
</ParamField>

<ParamField query="InsertedBy" type="StringSearchFilter">
  Filtra por el usuario o integración que creó la factura.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/sales-invoices?start=2026-10-01T00:00:00Z&end=2026-10-31T23:59:59Z&skip=0&take=20" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/sales-invoices?start=2026-10-01T00:00:00Z&end=2026-10-31T23:59:59Z&skip=0&take=20", {
  method: "GET",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
  },
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/sales-invoices",
    params={
        "start": "2026-10-01T00:00:00Z",
        "end": "2026-10-31T23:59:59Z",
        "skip": 0,
        "take": 20,
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>
