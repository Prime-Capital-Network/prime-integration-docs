---
title: "Crear"
api: "POST /attachments"
---

Sube un nuevo adjunto (attachment) y lo asocia a un registro específico del sistema.

<Note>
  Este endpoint requiere el scope **`Attachments.Write`**.
</Note>

<Note>
  Todos los parámetros de este endpoint, incluyendo el archivo, se envían en el body como `multipart/form-data`.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Body parameters

<ParamField body="name" type="string" required>
  Nombre del adjunto. Máximo 80 caracteres.
</ParamField>

<ParamField body="description" type="string" required>
  Descripción del adjunto. Máximo 1000 caracteres.
</ParamField>

<ParamField body="menuId" type="string" required>
  Identificador del menú (módulo) al cual pertenece el registro asociado.
</ParamField>

<ParamField body="recordId" type="string" required>
  Identificador del registro al cual se asocia el adjunto.
</ParamField>

<ParamField body="trackingId" type="integer">
  Identificador de seguimiento (tracking) al cual asociar el adjunto.
</ParamField>

<ParamField body="categoryId" type="integer">
  Identificador de la categoría del adjunto.
</ParamField>

<ParamField body="file" type="file" required>
  Archivo a adjuntar.
  
  - Tamaño máximo permitido: 10 MB.
  
  Extensiones permitidas: 

  - `jpg`
  - `jpeg`
  - `jpe`
  - `jfif`
  - `pjpeg`
  - `pjp`
  - `png`
  - `pdf`
  - `doc`
  - `docx`
  - `cvs`
  - `txt`
  - `xml`
  - `msg`
  - `xls`
  - `xlsx`
  - `ppt`
  - `pptx`
  - `pps`
  - `bmp`
  - `htm`
  - `tiff`
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request POST \
  --url "https://api.primenetcloud.com/v1/attachments" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID" \
  --header "Content-Type: multipart/form-data" \
  --form "name=Factura escaneada" \
  --form "description=Copia escaneada de la factura original" \
  --form "menuId=houses" \
  --form "recordId=1054" \
  --form "categoryId=2" \
  --form "file=@/path/to/file.pdf"
```

```python Python
import requests

files = {
    "file": open("/path/to/file.pdf", "rb")
}
data = {
    "name": "Factura escaneada",
    "description": "Copia escaneada de la factura original",
    "menuId": "houses",
    "recordId": "1054",
    "categoryId": 2,
}

response = requests.post(
    "https://api.primenetcloud.com/v1/attachments",
    data=data,
    files=files,
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

### Response fields

<ResponseField name="id" type="integer">
  Identificador único del adjunto creado.
</ResponseField>

### Errores

<ResponseField name="400 Bad Request">
  El archivo excede el tamaño máximo permitido (10 MB), o el tenant ha excedido la cuota de almacenamiento.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `Attachments.Write` requerido.
</ResponseField>
