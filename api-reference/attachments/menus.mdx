title: "Menús para adjuntos"
sidebarTitle: "Menús"

---

Cada adjunto se asocia a un registro mediante el par `menuId` + `recordId`: `menuId` indica el módulo del registro y `recordId` su identificador (el `id` que devuelve el endpoint de ese recurso).

- El registro debe existir en el módulo indicado; de lo contrario, la solicitud será rechazada con un error `400 Bad Request`.
- Los menús son fijos: no pueden crearse ni modificarse.

### Adjuntos con `trackingId`

Si se envía `trackingId`, el `menuId` debe ser uno de los módulos de operaciones logísticas: `quotations`, `shipments`, `houses`, `customs`, `groundtransportations` o `miscellaneous`. De lo contrario, la solicitud será rechazada con un error `400 Bad Request`.
