---

Obtén una lista paginada de las plantillas de solicitud configuradas en la empresa.

<Note>
  Este endpoint requiere el scope **`RequestTemplates.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Query parameters

<ParamField query="filter_by" type="string">
  Valores aceptados:

  - `Active`
</ParamField>

<ParamField query="skip" default="0" type="integer">
  Número de registros a omitir desde el inicio de los resultados. Utilízado junto con `take` para paginar los resultados.
</ParamField>

<ParamField query="take" default="20" type="integer">
  Número de registros a retornar. Por defecto `20`, máximo `100`.
</ParamField>

<ParamField query="name" type="StringSearchFilter">
  Filtra por el nombre de la plantilla.
</ParamField>

<ParamField query="OriginMenu.Name" type="StringSearchFilter">
  Filtra por el nombre traducido del menú de origen.
</ParamField>

<ParamField query="DestinationMenu.Name" type="StringSearchFilter">
  Filtra por el nombre traducido del menú de destino.
</ParamField>

<ParamField query="subject" type="StringSearchFilter">
  Filtra por el asunto de la plantilla.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/request-templates?filter_by=Active&skip=0&take=20" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch(
  "https://api.primenetcloud.com/v1/request-templates?filter_by=Active&skip=0&take=20",
  {
    method: "GET",
    headers: {
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID",
    },
  }
);

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/request-templates",
    params={
        "filter_by": "Active",
        "skip": 0,
        "take": 20,
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

```json
        "name": "string"
      },
      "destinationMenu": {
        "name": "string"

      "isActive": true
    }
  ]

```

### Response fields

<ResponseField name="totalCount" type="integer">
  Total de registros.
</ResponseField>

<ResponseField name="data" type="array">
  Lista de objetos RequestTemplate.

  <Expandable title="RequestTemplate">
    <ResponseField name="id" type="integer">
      Identificador único de la plantilla.
    </ResponseField>

    <ResponseField name="name" type="string">
      Nombre de la plantilla.
    </ResponseField>

    <ResponseField name="originMenu" type="object">
      Menú de origen de la plantilla.

      <Expandable title="propiedades">
        <ResponseField name="name" type="string">
          Nombre traducido del menú de origen.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="destinationMenu" type="object">
      Menú de destino de la plantilla.

      <Expandable title="propiedades">
        <ResponseField name="name" type="string">
          Nombre traducido del menú de destino.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="subject" type="string">
      Asunto que se asignará a las solicitudes creadas a partir de esta plantilla.
    </ResponseField>

    <ResponseField name="isActive" type="boolean">
      Indica si la plantilla está activa.
    </ResponseField>
  </Expandable>
</ResponseField>

### Errores

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `RequestTemplates.Read` requerido.
</ResponseField>
