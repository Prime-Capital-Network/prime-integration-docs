---
title: "Listar Rangos de una Plantilla"
sidebarTitle: "Listar rangos"
description: "Permite listar los rangos de autorización de una plantilla de solicitud mediante REST API"
api: "GET /request-templates/{id}/ranges"
---

Obtén el listado de rangos de autorización configurados en una plantilla de solicitud. Estos rangos aplican cuando la plantilla tiene `authorization.id` igual a `Range`, y determinan qué participante autoriza la solicitud según el monto.

<Note>
  Este endpoint requiere el scope **`RequestTemplates.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único de la plantilla de solicitud.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/request-templates/4/ranges" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch(
  "https://api.primenetcloud.com/v1/request-templates/4/ranges",
  {
    method: "GET",
    headers: {
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID",
    },
  }
);

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/request-templates/4/ranges",
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>
