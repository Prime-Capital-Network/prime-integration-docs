title: "Actualizar estatus de facturación"

Cambia el estatus de facturación de una operación logística, para marcarla como disponible o no disponible para facturar.

<Note>
  Este endpoint requiere el scope **`OperationBillingStatuses.Write`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Body parameters

<ParamField body="operationId" type="integer" required>
  Identificador de la operación logística, según el campo `operationCategory`.
</ParamField>

<ParamField body="operationCategory" type="string" required>
  Categoría de la operación logística. Valores aceptados:

  - `Shipment` (Embarque)
  - `CustomManagement` (Aduanas)
  - `Additional` (Misceláneos)
  - `InlandFreight` (Transporte Terrestre)
</ParamField>

<ParamField body="status" type="string" required>
  Nuevo estatus de facturación. Valores aceptados:

  - `NotAvailable` (No disponible para facturar)
  - `AvailableForBilling` (Disponible para facturar)
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request PUT \
  --url "https://api.primenetcloud.com/v1/operation-billing-status" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID" \
  --header "Content-Type: application/json" \
  --data '{
    "operationId": 5321,
    "operationCategory": "Shipment",
    "status": "AvailableForBilling"
  }'
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/operation-billing-status", {
  method: "PUT",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
    "Content-Type": "application/json",
  },
```

```python Python
import requests

response = requests.put(
    "https://api.primenetcloud.com/v1/operation-billing-status",
    json={
        "operationId": 5321,
        "operationCategory": "Shipment",
        "status": "AvailableForBilling",
    },
    headers={

        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.status_code)
```

</CodeGroup>

### Response

Si el cambio es exitoso, el endpoint retorna `204 No Content` sin body. Enviar el mismo estatus que ya tiene la operación también retorna `204 No Content` y no realiza ningún cambio.

Cuando la operación pasa a `AvailableForBilling`, se envía la alerta de operaciones disponibles para facturar al usuario o grupo configurado en la empresa.

### Errores

<ResponseField name="400 Bad Request">
  La solicitud será rechazada si:

  - `status` es `PartiallyBilled` o `Billed`.
  - La operación está cancelada.
  - La operación ya tiene facturas posteadas (estatus `PartiallyBilled` o `Billed`).
</ResponseField>

<ResponseField name="404 Not Found">
  No existe ninguna operación con el `operationId` especificado en la categoría `operationCategory`.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `OperationBillingStatuses.Write` requerido.
</ResponseField>
