Obtén una lista paginada de almacenes de inventario (compras) en la empresa.

<Note>
  Este endpoint requiere el scope **`Storerooms.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Query parameters

<ParamField query="filter_by" type="string">
  Filtro rápido de estado. Valor aceptado:

  - `Active` — retorna únicamente almacenes activos.

  Si se omite, retorna todos los almacenes (activos e inactivos).
</ParamField>

<ParamField query="skip" default="0" type="integer">
  Número de registros a omitir desde el inicio de los resultados. Utilízalo junto con `take` para paginar los resultados.
</ParamField>

<ParamField query="take" default="20" type="integer">
  Número de registros a retornar. Por defecto `20`, máximo `100`.
</ParamField>

<ParamField query="code" type="StringSearchFilter">
  Filtra por el código del almacén.
</ParamField>

<ParamField query="name" type="StringSearchFilter">
  Filtra por el nombre del almacén.
</ParamField>

<ParamField query="location" type="StringSearchFilter">
  Filtra por la localización (dirección) del almacén.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/storerooms?filter_by=Active&skip=0&take=20" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch(
  "https://api.primenetcloud.com/v1/storerooms?filter_by=Active&skip=0&take=20",
  {
    method: "GET",
    headers: {
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID",
    },
  }
);

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/storerooms",
    params={
        "filter_by": "Active",
        "skip": 0,
        "take": 20,
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Example response

```json
{
  "totalCount": 1,
  "data": [
    {
      "id": 3,
      "code": "ALM-01",
      "name": "Almacén Principal",
      "location": "Zona Franca Las Américas, Nave 4",
      "isActive": true
    }
  ]
}
```

### Response fields

<ResponseField name="totalCount" type="integer">
  Total de registros.
</ResponseField>

<ResponseField name="data" type="array">
  Lista de objetos Storeroom.

  <Expandable title="Storeroom">
    <ResponseField name="id" type="integer">
      Identificador único del almacén.
    </ResponseField>
    <ResponseField name="code" type="string">
      Código del almacén.
    </ResponseField>
    <ResponseField name="name" type="string">
      Nombre del almacén.
    </ResponseField>
    <ResponseField name="location" type="string">
      Localización o dirección del almacén. `null` si no aplica.
    </ResponseField>
    <ResponseField name="isActive" type="boolean">
      Indica si el almacén está activo.
    </ResponseField>
  </Expandable>
</ResponseField>

### Errores

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `Storerooms.Read` requerido.
</ResponseField>
