---

Busca almacenes de inventario activos por nombre o código, para búsqueda rápida (por ejemplo, autocompletar en formularios).

<Note>
  Este endpoint requiere el scope **`Storerooms.Read`**.
</Note>

<Note>
  Este endpoint solo retorna almacenes activos; no incluye registros inactivos.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Query parameters

<ParamField query="value" type="string">
  Texto libre para buscar por nombre o código del almacén.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/storerooms/search?value=Principal" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch(
  "https://api.primenetcloud.com/v1/storerooms/search?value=Principal",
  {
    method: "GET",
    headers: {
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID",
    },
  }
);

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/storerooms/search",
    params={
        "value": "Principal",
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Example response

```json
[
  {
    "id": 3,
    "code": "ALM-01",
    "name": "Almacén Principal"
  }
]
```

### Response fields

<ResponseField name="id" type="integer">
  Identificador único del almacén.
</ResponseField>

<ResponseField name="code" type="string">
  Código del almacén.
</ResponseField>

<ResponseField name="name" type="string">
  Nombre del almacén.
</ResponseField>

### Errores

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `Storerooms.Read` requerido.
</ResponseField>
