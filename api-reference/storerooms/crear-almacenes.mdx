Crea un nuevo almacén de inventario.

<Note>
  Este endpoint requiere el scope **`Storerooms.Write`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Body parameters

<ParamField body="code" type="string" required>
  Código del almacén. Máximo 10 caracteres. No se permiten códigos duplicados.
</ParamField>

<ParamField body="name" type="string" required>
  Nombre del almacén. Máximo 60 caracteres. Debe ser único entre todos los almacenes de inventario.
</ParamField>

<ParamField body="location" type="string">
  Localización o dirección del almacén. Máximo 250 caracteres.
</ParamField>

<ParamField body="isActive" type="boolean" default="true">
  Indica si el almacén queda activo al crearse.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request POST \
  --url "https://api.primenetcloud.com/v1/storerooms" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID" \
  --header "Content-Type: application/json" \
  --data '{
    "code": "ALM-01",
    "name": "Almacén Principal",
    "location": "Zona Franca Las Américas, Nave 4"
  }'
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/storerooms", {
  method: "POST",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    code: "ALM-01",
    name: "Almacén Principal",
    location: "Zona Franca Las Américas, Nave 4",
  }),
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.post(
    "https://api.primenetcloud.com/v1/storerooms",
    json={
        "code": "ALM-01",
        "name": "Almacén Principal",
        "location": "Zona Franca Las Américas, Nave 4",
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Example response

```json
{
  "id": 3
}
```

### Response fields

<ResponseField name="id" type="integer">
  Identificador único del almacén de inventario creado.
</ResponseField>

### Errores

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `Storerooms.Write` requerido.
</ResponseField>
