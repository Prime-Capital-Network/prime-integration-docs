api: "PUT /storerooms/{id}/locations/{locationId}"
---

Actualiza una localización de un almacén de inventario.

<Note>
  Este endpoint requiere el scope **`Storerooms.Write`**.
</Note>

<Warning>
  Este es un reemplazo completo del recurso (PUT). Todos los campos enviados en el body sobrescribirán el estado actual de la localización.
</Warning>

<Tip>
  No existe un endpoint para eliminar localizaciones. Para desactivar una localización, envía `isActive: false` mediante este mismo endpoint.
</Tip>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="integer" required>
  Identificador único del almacén de inventario al que pertenece la localización.
</ParamField>

<ParamField path="locationId" type="integer" required>
  Identificador único de la localización a actualizar.
</ParamField>

### Body parameters

<ParamField body="code" type="string" required>
  Código de la localización. Máximo 20 caracteres. Debe ser único dentro del almacén de la localización.
</ParamField>

<ParamField body="aisle" type="string">
  Pasillo. Máximo 20 caracteres.
</ParamField>

<ParamField body="row" type="string">
  Fila. Máximo 20 caracteres.
</ParamField>

<ParamField body="bin" type="string">
  Bin / casilla. Máximo 20 caracteres.
</ParamField>

<ParamField body="description" type="string">
  Descripción de la localización. Máximo 100 caracteres.
</ParamField>

<ParamField body="isActive" type="boolean" default="true">
  Indica si la localización está activa.
</ParamField>

<Note>
  El almacén de una localización no se puede cambiar después de creada: los movimientos de inventario guardan almacén y localización juntos, y permitir el cambio dejaría el histórico inconsistente.
</Note>

### Example request

<CodeGroup>

```bash curl
curl --request PUT \
  --url "https://api.primenetcloud.com/v1/storerooms/3/locations/12" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID" \
  --header "Content-Type: application/json" \
  --data '{
    "code": "A-01-03",
    "aisle": "A",
    "row": "01",
    "bin": "03",
    "description": "Repisa de electrónicos"
  }'
```

```javascript JavaScript
const response = await fetch("https://api.primenetcloud.com/v1/storerooms/3/locations/12", {
  method: "PUT",
  headers: {
    "X-Api-Key": "YOUR_API_KEY",
    "X-Tenant-Id": "TENANT_ID",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    code: "A-01-03",
    aisle: "A",
    row: "01",
    bin: "03",
    description: "Repisa de electrónicos",
  }),
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.put(
    "https://api.primenetcloud.com/v1/storerooms/3/locations/12",
    json={
        "code": "A-01-03",
        "aisle": "A",
        "row": "01",
        "bin": "03",
        "description": "Repisa de electrónicos",
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Response

Si la actualización es exitosa, el endpoint retorna `204 No Content` sin body.

### Errores

<ResponseField name="404 Not Found">
  No existe ninguna localización con el `locationId` especificado, o no pertenece al almacén indicado en `id`.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `Storerooms.Write` requerido.
</ResponseField>

<RequestExample>

```json
{
  "code": "A-01-03",
  "aisle": "A",
  "row": "01",
  "bin": "03",
  "description": "Repisa de electrónicos",
  "isActive": true
}
```

</RequestExample>
