---
title: "Obtener Tipo de Contenedor Por ID"
sidebarTitle: "Obtener por ID"
description: "Permite extraer un tipo de contenedor en específico mediante REST API"
api: "GET /container-types/{id}"
---

Obtén un tipo de contenedor por ID en la empresa.

<Note>
  Este endpoint requiere el scope **`ContainerTypes.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Path parameters

<ParamField path="id" type="string" required>
  Identificador único del tipo de contenedor.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/container-types/40HC" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch(
  "https://api.primenetcloud.com/v1/container-types/40HC",
  {
    method: "GET",
    headers: {
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID",
    },
  }
);

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/container-types/40HC",
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Response fields

<ResponseField name="id" type="string">
  Identificador único del tipo de contenedor.
</ResponseField>

<ResponseField name="name" type="string">
  Nombre del tipo de contenedor.
</ResponseField>

<ResponseField name="size" type="integer">
  Tamaño (en pies) del tipo de contenedor.
</ResponseField>

<ResponseField name="teu" type="decimal">
  Equivalencia en TEU (Twenty-foot Equivalent Unit) del tipo de contenedor.
</ResponseField>

<ResponseField name="kilogramMaxCapacity" type="integer">
  Capacidad máxima en kilogramos.
</ResponseField>

<ResponseField name="poundMaxCapacity" type="decimal">
  Capacidad máxima en libras.
</ResponseField>

<ResponseField name="cubicMeterMaxCapacity" type="decimal">
  Capacidad máxima en metros cúbicos.
</ResponseField>

<ResponseField name="cubicFootMaxCapacity" type="decimal">
  Capacidad máxima en pies cúbicos.
</ResponseField>

<ResponseField name="insertedBy" type="string">
  Usuario que creó el registro.
</ResponseField>

<ResponseField name="insertedDate" type="string">
  Fecha y hora de creación del registro, en formato ISO 8601.
</ResponseField>

<ResponseField name="updatedBy" type="string">
  Usuario que realizó la última actualización del registro.
</ResponseField>

<ResponseField name="updatedDate" type="string">
  Fecha y hora de la última actualización, en formato ISO 8601.
</ResponseField>

<ResponseField name="isActive" type="boolean">
  Indica si el tipo de contenedor está activo.
</ResponseField>

### Errores

<ResponseField name="404 Not Found">
  No existe ningún tipo de contenedor con el `id` especificado en la URL.
</ResponseField>

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `ContainerTypes.Read` requerido.
</ResponseField>
