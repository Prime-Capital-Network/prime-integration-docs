Obtén una lista paginada de tipos de contenedor en la empresa.

<Note>
  Este endpoint requiere el scope **`ContainerTypes.Read`**.
</Note>

### Headers

<ParamField header="X-Tenant-Id" type="string" required>
  Identificador del tenant al cual pertenece el API Key.
</ParamField>

### Query parameters

<ParamField query="filter_by" type="string">
  Valores aceptados:

  - `Active`
</ParamField>

<ParamField query="sort_by" type="string">
  Campo por el cual ordenar los resultados. Valores aceptados:

  - `Id`
  - `Name`
  - `Size`
</ParamField>

<ParamField query="skip" default="0" type="integer">
  Número de registros a omitir desde el inicio de los resultados. Utilízado junto con `take` para paginar los resultados.
</ParamField>

<ParamField query="take" default="20" type="integer">
  Número de registros a retornar. Por defecto `20`, máximo `100`.
</ParamField>

<ParamField query="Name" type="StringSearchFilter">
  Filtra por el nombre del tipo de contenedor.
</ParamField>

<ParamField query="Size" type="RangeSearchFilter<integer>">
  Filtra por el tamaño (en pies) del tipo de contenedor.
</ParamField>

<ParamField query="KilogramMaxCapacity" type="RangeSearchFilter<integer>">
  Filtra por la capacidad máxima en kilogramos.
</ParamField>

<ParamField query="PoundMaxCapacity" type="RangeSearchFilter<decimal>">
  Filtra por la capacidad máxima en libras.
</ParamField>

<ParamField query="CubicMeterMaxCapacity" type="RangeSearchFilter<decimal>">
  Filtra por la capacidad máxima en metros cúbicos.
</ParamField>

<ParamField query="CubicFootMaxCapacity" type="RangeSearchFilter<decimal>">
  Filtra por la capacidad máxima en pies cúbicos.
</ParamField>

### Example request

<CodeGroup>

```bash curl
curl --request GET \
  --url "https://api.primenetcloud.com/v1/container-types?filter_by=Active&take=20" \
  --header "X-Api-Key: YOUR_API_KEY" \
  --header "X-Tenant-Id: TENANT_ID"
```

```javascript JavaScript
const response = await fetch(
  "https://api.primenetcloud.com/v1/container-types?filter_by=Active&take=20",
  {
    method: "GET",
    headers: {
      "X-Api-Key": "YOUR_API_KEY",
      "X-Tenant-Id": "TENANT_ID",
    },
  }
);

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    "https://api.primenetcloud.com/v1/container-types",
    params={
        "filter_by": "Active",
        "take": 20,
    },
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "X-Tenant-Id": "TENANT_ID",
    },
)

print(response.json())
```

</CodeGroup>

### Response fields

<ResponseField name="totalCount" type="integer">
  Total de registros.
</ResponseField>

<ResponseField name="data" type="array">
  Lista de objetos ContainerType.

  <Expandable title="ContainerType">
    <ResponseField name="id" type="string">
      Identificador único del tipo de contenedor.
    </ResponseField>

    <ResponseField name="name" type="string">
      Nombre del tipo de contenedor.
    </ResponseField>

    <ResponseField name="size" type="integer">
      Tamaño (en pies) del tipo de contenedor.
    </ResponseField>

    <ResponseField name="teu" type="decimal">
      Equivalencia en TEU (Twenty-foot Equivalent Unit) del tipo de contenedor.
    </ResponseField>

    <ResponseField name="kilogramMaxCapacity" type="integer">
      Capacidad máxima en kilogramos.
    </ResponseField>

    <ResponseField name="poundMaxCapacity" type="decimal">
      Capacidad máxima en libras.
    </ResponseField>

    <ResponseField name="cubicMeterMaxCapacity" type="decimal">
      Capacidad máxima en metros cúbicos.
    </ResponseField>

    <ResponseField name="cubicFootMaxCapacity" type="decimal">
      Capacidad máxima en pies cúbicos.
    </ResponseField>

    <ResponseField name="isActive" type="boolean">
      Indica si el tipo de contenedor está activo.
    </ResponseField>
  </Expandable>
</ResponseField>

### Errores

<ResponseField name="403 Forbidden">
  El API Key no tiene el scope `ContainerTypes.Read` requerido.
</ResponseField>
